# 3. What Is Calculus?

Calculus is the branch of mathematics that studies:

1. Change
2. Motion
3. Growth
4. Rates of change

At its core, calculus answers questions like:

* How fast is something changing?
* What direction should we move?
* How can we find the maximum or minimum value of a function?

---

## Example: Distance vs Time

Suppose a car travels:

-------------------code----------------------
Time (hours)    Distance (km)

0               0
1               60
2               120
3               180
-------------------code----------------------

The car's position changes over time.

Calculus helps answer:

> "How fast is the car moving at a specific moment?"

This leads directly to derivatives.

## Example

Suppose a model predicts:

[

]

Where:

* (x) = input
* (w) = weight

* (y) = prediction

We want to know:

> "If I change (w) slightly, how does the prediction change?"

Calculus provides the answer.

# 5. Differentiation

A major focus of this subject is:

## Differentiation

Differentiation computes a derivative.

A derivative tells us:

> How quickly a function changes.

Example:

[
f(x)=x^2
]

The derivative is:

[
f'(x)=2x
]

Meaning:

* At x = 1 → slope = 2
* At x = 2 → slope = 4
* At x = 3 → slope = 6

The slope changes depending on where you are on the curve.

---

# 6. Why Derivatives Matter in Deep Learning

Most deep learning algorithms learn using:

## Backpropagation

and

## Stochastic Gradient Descent (SGD)

These methods repeatedly compute derivatives.

---

### Training Process

-------------------code----------------------

      ↓

      ↓
Derivative

Better Prediction
-------------------code----------------------

Without derivatives:

* Neural networks cannot learn.
* Optimization becomes extremely difficult.

# 7. Automatic Differentiation

A major theme later in this subject is:

## Automatic Differentiation (Autograd)

Instead of calculating derivatives by hand:

-------------------code----------------------
# Manual derivative
def derivative(x):
    return 2 * x
-------------------code----------------------

Modern frameworks calculate derivatives automatically.

Examples:

### PyTorch

-------------------code----------------------
import torch

x = torch.tensor(2.0, requires_grad=True)

y = x ** 2

y.backward()

print(x.grad)
-------------------code----------------------

Output:

-------------------code----------------------
tensor(4.)
-------------------code----------------------

PyTorch automatically computes:

[
\frac{d}{dx}(x^2)=2x
]

and evaluates it at x=2.

* Understand slopes

* Differentiate functions

# Complete Introductory Code Example

-------------------code----------------------
import numpy as np
import torch

# Function
def f(x):
    return x**2

# Evaluate function
x = 2

print("f(x):", f(x))

# Manual derivative
manual_derivative = 2 * x

print("Manual derivative:", manual_derivative)

# Automatic differentiation with PyTorch
x_torch = torch.tensor(
    2.0,
    requires_grad=True
)

y = x_torch ** 2

y.backward()

print(
    "PyTorch derivative:",
    x_torch.grad.item()
)
-------------------code----------------------

Expected Output:

-------------------code----------------------

Manual derivative: 4
PyTorch derivative: 4
