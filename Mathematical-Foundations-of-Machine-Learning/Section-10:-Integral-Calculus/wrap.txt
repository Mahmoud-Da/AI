## 2. Differentiation vs. Integration

Differentiation and integration are two major branches of calculus.

### 2.1 Differentiation

Differentiation measures how a function changes as its input changes.

For example, if

\\[ f(x)=x^2 \\]

then its derivative is

\\[ f'(x)=2x \\]

Python code using SymPy:

-------------------code----------------------

-------------------code----------------------

Expected output:

-------------------code----------------------

Derivative: 2*x
-------------------code----------------------

In machine learning, derivatives help calculate gradients, which are used by optimization algorithms to update model parameters and reduce the loss.

### 2.2 Integration

Integration can be used to calculate accumulated quantities and the area under a curve.

For example,

\\[ \int x^2\\,dx=\frac{x^3}{3}+C \\]

Here, \\(C\\) is the constant of integration.

Python code:

-------------------code----------------------

-------------------code----------------------

Expected output:

-------------------code----------------------

Indefinite integral: x**3/3
-------------------code----------------------

Important distinction: An indefinite integral gives a family of antiderivatives, while a definite integral calculates an accumulated value over a specified interval.

For example,

\\[ \int_0^2 x^2\\,dx=\frac{8}{3} \\]

## 4. The Confusion Matrix

A confusion matrix summarizes the relationship between a classifier's predictions and the actual classes.

For a binary classifier, the four possible outcomes are:

|                    | Actual positive     | Actual negative     |
| ------------------ | ------------------- | ------------------- |
| Predicted positive | True Positive (TP)  | False Positive (FP) |
| Predicted negative | False Negative (FN) | True Negative (TN)  |

- True Positive (TP): The model correctly predicts the positive class.
- False Positive (FP): The model predicts positive when the actual class is negative.
- False Negative (FN): The model predicts negative when the actual class is positive.
- True Negative (TN): The model correctly predicts the negative class.

The lecture plans to use the confusion matrix as the starting point for constructing the ROC curve.

No specific dataset or confusion-matrix calculation is provided in this introductory lecture.

## 5. The ROC Curve and AUC

### 5.1 ROC curve

ROC stands for Receiver Operating Characteristic.

An ROC curve illustrates how a binary classifier's true positive rate changes in relation to its false positive rate as the classification threshold changes.

The two axes are:

- True Positive Rate (TPR): The proportion of actual positive examples correctly identified.
- False Positive Rate (FPR): The proportion of actual negative examples incorrectly classified as positive.

Their formulas are:

\\[ TPR=\frac{TP}{TP+FN} \\]

\\[ FPR=\frac{FP}{FP+TN} \\]

These formulas provide the basic quantities used to construct an ROC curve.

### 5.2 Area Under the Curve (AUC)

AUC stands for Area Under the Curve. In this context, it means the area under the ROC curve.

Integration provides a mathematical method for calculating that area.

For an ROC curve represented by \\(TPR\\) as a function of \\(FPR\\), the area can be expressed as

\\[ AUC=\int_0^1 TPR(FPR)\\,d(FPR) \\]

This expression describes the mathematical objective. The actual calculation methods and application to a classifier will be covered in later lectures.

4. How a classification threshold converts model outputs into class predictions.

6. Why the ROC curve and Area Under the Curve (ROC AUC) provide a different way to evaluate binary classifiers.

## 2. Supervised Learning

Supervised learning is a machine learning approach in which a model learns to map an input \\(X\\) to a target outcome \\(Y\\).

The objective is to learn a function that approximates the relationship between them:

\\[ \hat{Y}=f(X) \\]

Where:

- \\(X\\): The input features provided to the model.
- \\(Y\\): The actual target or outcome.
- \\(\hat{Y}\\): The model's prediction.
- \\(f\\): The function learned by the model.

For example, a model might use information about a patient and a drug dosage to predict an outcome related to forgetfulness.

Supervised learning has two major problem categories: regression and classification.

## 3. Regression vs. Classification

### 3.1 Regression

Regression predicts a numerical value.

Examples from the lecture include:

- Medical outcomes: Predicting a numerical measure of a patient's forgetfulness based on an Alzheimer's drug dosage.
- Product sales: Predicting whether a product will generate 10,000 or 15,000 sales next quarter.
- Asset valuation: Predicting the future price of a stock, house, or other asset.

The target is a numerical quantity rather than a category.

Example code:

-------------------code----------------------
# Example: regression prediction

# Input feature: drug dosage
drug_dosage = 5.0

# Simplified example of a regression model
def predict_forgetfulness(dosage):
    return 20.0 - 2.0 * dosage

prediction = predict_forgetfulness(drug_dosage)

print("Predicted forgetfulness:", prediction)
-------------------code----------------------

This simplified example predicts a number. The function is illustrative and is not a trained medical model.

### 3.2 Classification

Classification predicts which category an input belongs to.

Examples include:

- Determining whether a movie review is positive or negative.
- Identifying which handwritten digit appears in an image.
- Determining whether a food image contains a hot dog.

Unlike regression, classification predicts a class rather than a continuous numerical target.

Example code:

-------------------code----------------------
# Example: classification prediction

review_sentiment = "This movie was excellent!"

def classify_review(review):
    if "excellent" in review.lower():
        return "positive"
    return "negative"

prediction = classify_review(review_sentiment)

print("Predicted class:", prediction)
-------------------code----------------------

This is a simple rule-based illustration of classification, not a machine learning model trained on review data.

## 5. Model Outputs and Classification Thresholds

### 5.1 Understanding outputs between 0 and 1

Many binary classification models produce a score between 0 and 1. When the output is interpreted as a probability, it represents the model's estimated probability that the input belongs to the positive class.

For the hot dog example:

| Model output | Interpretation                              |
| ------------ | ------------------------------------------- |
| 0.01         | Very low estimated probability of a hot dog |
| 0.30         | Relatively low estimated probability        |
| 0.50         | Estimated probability of 50%                |
| 0.90         | High estimated probability                  |
| 0.99         | Very high estimated probability             |

These interpretations assume the output is a probability estimate. Not every model score is automatically a well-calibrated probability.

### 5.2 Converting an output into a class

A threshold converts a continuous score into a discrete class prediction.

The lecture uses the common threshold of \\(0.5\\):

\\[ \hat{y}= \begin{cases} 1 & \text{if } p\geq 0.5\\\ 0 & \text{if } p<0.5 \end{cases} \\]

Here:

- \\(p\\) is the model's output for the positive class.
- Class `1` represents the positive class, such as “hot dog.”
- Class `0` represents the negative class, such as “not a hot dog.”

Example code:

-------------------code----------------------
# Step 1: Define the classification threshold
threshold = 0.5

# Step 2: Supply example model outputs
predictions = [0.05, 0.30, 0.49, 0.51, 0.90, 0.99]

# Step 3: Convert each score into a class prediction
for probability in predictions:
    if probability >= threshold:
        predicted_class = "hot dog"
    else:
        predicted_class = "not a hot dog"

    print(
        f"Score: {probability:.2f} -> "
        f"Prediction: {predicted_class}"
    )
-------------------code----------------------

Expected output:

-------------------code----------------------
Score: 0.05 -> Prediction: not a hot dog
Score: 0.30 -> Prediction: not a hot dog
Score: 0.49 -> Prediction: not a hot dog
Score: 0.51 -> Prediction: hot dog
Score: 0.90 -> Prediction: hot dog
Score: 0.99 -> Prediction: hot dog
-------------------code----------------------

The threshold simplifies the model's output into a class. However, it also discards information about how far the score is from the threshold.

## 6. Limitation 1: A Single Threshold Hides Information

Consider two models that classify the same dataset.

- Model A produces many scores close to 0.5.
- Model B produces more scores close to 0 and 1.

Model B appears more confident in its predictions because its scores are more extreme.

For example:

-------------------code----------------------
# Step 1: Example outputs from two models
model_a = [0.45, 0.52, 0.48, 0.55, 0.40]
model_b = [0.05, 0.95, 0.10, 0.90, 0.02]

# Step 2: Apply the same threshold to both models
threshold = 0.5

def classify(scores):
    return [1 if score >= threshold else 0 for score in scores]

# Step 3: Display the resulting class predictions
print("Model A scores:", model_a)
print("Model A classes:", classify(model_a))

print("Model B scores:", model_b)
print("Model B classes:", classify(model_b))
-------------------code----------------------

The resulting class predictions are:

-------------------code----------------------
Model A classes: [0, 1, 0, 1, 0]
Model B classes: [0, 1, 0, 1, 0]
-------------------code----------------------

Both models produce exactly the same class predictions at the threshold of 0.5, even though their output scores differ substantially.

This demonstrates the lecture's main point: evaluating only the thresholded predictions can hide differences in the models' output scores.

An important qualification is that more extreme scores do not automatically mean a model is better. The scores must be evaluated against the actual labels and the model's behavior across different thresholds.

## 7. Limitation 2: Predictions Near the Threshold Are Treated Abruptly

Suppose the actual class is positive, meaning the image really does contain a hot dog.

Compare these model outputs:

- Model output of `0.49`: classified as negative.
- Model output of `0.51`: classified as positive.
- Model output of `0.99`: classified as positive.

With a threshold of 0.5, the first prediction is counted as incorrect, while the other two are counted as correct.

However, the scores `0.49` and `0.51` are extremely close. A small difference in the score produces a different class prediction.

Meanwhile, `0.51` and `0.99` both receive the same class label, despite expressing very different estimated probabilities.

Example code:

-------------------code----------------------
# Step 1: Define the actual class
actual_class = 1  # Positive class

# Step 2: Define three model scores
scores = [0.49, 0.51, 0.99]
threshold = 0.5

# Step 3: Convert scores into predicted classes
for score in scores:
    predicted_class = 1 if score >= threshold else 0

    # Step 4: Compare prediction with the actual class
    correct = predicted_class == actual_class

    print(
        f"Score: {score:.2f}, "
        f"Predicted class: {predicted_class}, "
        f"Correct: {correct}"
    )
-------------------code----------------------

Expected output:

-------------------code----------------------
Score: 0.49, Predicted class: 0, Correct: False
Score: 0.51, Predicted class: 1, Correct: True
Score: 0.99, Predicted class: 1, Correct: True
-------------------code----------------------

The threshold makes a binary decision, but that decision alone does not express the degree of confidence represented by the score.

This is another reason to examine the model's performance using more than a single threshold.

## 8. The Solution: ROC AUC

The lecture introduces ROC AUC as an alternative metric for evaluating binary classification models.

ROC AUC stands for the Area Under the Receiver Operating Characteristic Curve.

The key idea is to evaluate model performance across a range of classification thresholds rather than relying exclusively on one threshold, such as 0.5.

### 8.1 What is the ROC curve?

The ROC curve plots two quantities at different thresholds:

- True Positive Rate (TPR): The proportion of actual positive examples correctly identified.
- False Positive Rate (FPR): The proportion of actual negative examples incorrectly classified as positive.

Their formulas are:

\\[ TPR=\frac{TP}{TP+FN} \\]

\\[ FPR=\frac{FP}{FP+TN} \\]

Where:

- \\(TP\\): True positives.
- \\(FN\\): False negatives.
- \\(FP\\): False positives.
- \\(TN\\): True negatives.

The following code calculates these rates for a single threshold. It does not yet generate the full ROC curve.

-------------------code----------------------
# Step 1: Define the confusion-matrix counts
TP = 80
FN = 20
FP = 10
TN = 90

# Step 2: Calculate the true positive rate
TPR = TP / (TP + FN)

# Step 3: Calculate the false positive rate
FPR = FP / (FP + TN)

# Step 4: Display the results
print(f"True Positive Rate: {TPR:.2f}")
print(f"False Positive Rate: {FPR:.2f}")
-------------------code----------------------

Expected output:

-------------------code----------------------
True Positive Rate: 0.80
False Positive Rate: 0.10
-------------------code----------------------

These rates represent one operating point on an ROC curve. A full ROC curve requires evaluating the model at multiple thresholds.

### 8.2 What does AUC measure?

AUC summarizes the area under the ROC curve into a single value.

Conceptually:

- A higher AUC generally indicates better discrimination between the positive and negative classes.
- An AUC of 1.0 represents perfect discrimination.
- An AUC of approximately 0.5 indicates discrimination comparable to random ranking under the usual binary-classification interpretation.

The lecture will explain how to construct the ROC curve and calculate its area in subsequent videos.

For now, the important distinction is:

A single-threshold metric evaluates predictions at one decision threshold, while ROC AUC summarizes ranking performance across thresholds.

## 9. Important Notes and Best Practices

1. Identify the problem type first.
   - Regression predicts numerical values.
   - Multiclass classification predicts one of several classes.
   - Binary classification predicts one of two classes.
2. Understand what a model score represents. A score between 0 and 1 can be interpreted as a probability when the model is designed to produce probability estimates. High confidence does not guarantee correctness.
3. Remember that the threshold is a decision rule. A threshold of 0.5 is common, but it is not always the best threshold for every application.
4. Do not evaluate a model using only its score distribution. More extreme scores do not prove better performance. Compare predictions against actual labels and evaluate performance appropriately.
5. Distinguish class predictions from model scores. Converting a score into a class discards information about how close the score is to the decision threshold.
6. Understand the ROC curve before studying AUC. The confusion matrix provides the counts needed to calculate TPR and FPR. These rates are used to construct the ROC curve.
7. Use the appropriate metric for the problem. ROC AUC is useful for comparing discrimination across thresholds, but it does not replace every other evaluation metric or determine the best decision threshold by itself.

## 10. Summary

The lecture establishes the foundations of binary classification evaluation.

- Supervised learning maps inputs \\(X\\) to target outcomes \\(Y\\).
- Regression predicts numerical values, while classification predicts categories.
- Classification problems can be multiclass or binary.
- Binary classification models often produce scores between 0 and 1.
- A threshold, commonly 0.5, converts these scores into class predictions.
- A single threshold can hide differences between models and treats scores on opposite sides of the threshold as different classes, even when their values are very close.
- ROC AUC addresses this limitation by summarizing discrimination performance across classification thresholds.
- The confusion matrix is the next essential step toward understanding ROC AUC.

def calculate_roc_points(labels, scores):
    """
    Calculate ROC points by testing thresholds from high
    to low. The input scores are assumed to represent
    the positive class.
    """
    if len(labels) != len(scores):
        raise ValueError(
            "Labels and scores must have the same length."
        )

    if not labels:
        raise ValueError("The dataset must not be empty.")

    if any(label not in (0, 1) for label in labels):
        raise ValueError("Labels must be 0 or 1.")

    if any(not 0 <= score <= 1 for score in scores):
        raise ValueError("Scores must be between 0 and 1.")

    total_positive = sum(labels)
    total_negative = len(labels) - total_positive

    if total_positive == 0 or total_negative == 0:
        raise ValueError(
            "ROC calculation requires both positive "
            "and negative examples."
        )

    # Include thresholds that produce the all-negative
    # and all-positive predictions.
    thresholds = (
        [float("inf")]
        + sorted(set(scores), reverse=True)
        + [float("-inf")]
    )

    roc_points = []

    for threshold_value in thresholds:
        predictions = [
            1 if score >= threshold_value else 0
            for score in scores
        ]

        TP_count = sum(
            actual == 1 and predicted == 1
            for actual, predicted in zip(labels, predictions)
        )

        FN_count = sum(
            actual == 1 and predicted == 0
            for actual, predicted in zip(labels, predictions)
        )

        FP_count = sum(
            actual == 0 and predicted == 1
            for actual, predicted in zip(labels, predictions)
        )

        TN_count = sum(
            actual == 0 and predicted == 0
            for actual, predicted in zip(labels, predictions)
        )

        TPR_value = TP_count / (TP_count + FN_count)
        FPR_value = FP_count / (FP_count + TN_count)

        roc_points.append(
            (FPR_value, TPR_value, threshold_value)
        )

    return roc_points


roc_points = calculate_roc_points(
    actual_labels,
    model_scores
)

print("\nSTEP 6: ROC points")

for fpr, tpr, threshold_value in roc_points:
    print(
        f"Threshold: {threshold_value:>5}, "
        f"FPR: {fpr:.2f}, "
        f"TPR: {tpr:.2f}"
    )


# ============================================================
# Step 7: Calculate ROC AUC using the trapezoidal rule
# ============================================================

def calculate_auc(roc_points):
    """
    Calculate the area under the ROC curve using
    the trapezoidal rule.

    Each ROC point has the form:
        (false_positive_rate, true_positive_rate, threshold)
    """
    # Sort points from lowest to highest FPR.
    points = sorted(
        (fpr, tpr) for fpr, tpr, _ in roc_points
    )

    area = 0.0

    for i in range(1, len(points)):
        previous_fpr, previous_tpr = points[i - 1]
        current_fpr, current_tpr = points[i]

        width = current_fpr - previous_fpr
        average_height = (
            previous_tpr + current_tpr
        ) / 2.0

        area += width * average_height

    return area


auc = calculate_auc(roc_points)

print("\nSTEP 7: ROC AUC")
print(f"Area Under the ROC Curve: {auc:.4f}")


# ============================================================
# Step 8: Interpret the result
# ============================================================

print("\nSTEP 8: Interpretation")

if auc > 0.5:
    print(
        "The model demonstrates better-than-random "
        "ranking on this example dataset."
    )
elif auc == 0.5:
    print(
        "The model's ranking performance is equivalent "
        "to random ranking on this example dataset."
    )
else:
    print(
        "The model's ranking is worse than random "
        "on this example dataset."
    )

print(
    "\nReminder: This is a small illustrative dataset. "
    "Real model evaluation requires representative data "
    "and additional appropriate metrics."
)

*** 96. The Confusion Matrix ***
# Machine Learning Foundations — The Confusion Matrix

## 1. Overview

A confusion matrix is a table used to evaluate a classification model by comparing its predictions with the actual outcomes.

It helps us identify:

- Correct positive predictions.
- Correct negative predictions.
- False positive predictions.
- False negative predictions.

The lecture uses a simple example: determining whether an image contains a hot dog.

The model can predict one of two classes:

- `1` = Hot dog.
- `0` = Not a hot dog.

The confusion matrix shows whether the model's predictions match reality.

## 2. Understand Actual vs. Predicted Values

Before constructing a confusion matrix, we must distinguish between actual outcomes and predicted outcomes.

- Actual \\(Y\\): What is really true in the real world.
- Predicted \\(\hat{Y}\\): What the model predicts.

For example:

| Actual value | Predicted value | Interpretation                                  |
| ------------ | --------------- | ----------------------------------------------- |
| 1            | 1               | Model predicts a hot dog, and one is present.   |
| 1            | 0               | Model predicts no hot dog, but one is present.  |
| 0            | 1               | Model predicts a hot dog, but none is present.  |
| 0            | 0               | Model predicts no hot dog, and none is present. |

The model is correct when the actual and predicted values match. It is incorrect when they differ.

## 3. The Four Outcomes of a Confusion Matrix

### 3.1 True Positive (TP)

The actual class is positive (`1`), and the model predicts positive (`1`).

Example: The image contains a hot dog, and the model correctly identifies it.

### 3.2 True Negative (TN)

The actual class is negative (`0`), and the model predicts negative (`0`).

Example: The image contains a pizza, and the model correctly predicts “not a hot dog.”

### 3.3 False Positive (FP)

The actual class is negative (`0`), but the model predicts positive (`1`).

Example: The image contains a pizza, but the model incorrectly identifies it as a hot dog.

### 3.4 False Negative (FN)

The actual class is positive (`1`), but the model predicts negative (`0`).

Example: The image contains a hot dog, but the model fails to identify it.

## 5. Important Notes and Best Practices

- Remember the actual-versus-predicted distinction. The actual class represents reality; the predicted class represents the model's decision.
- “True” and “false” refer to correctness. “Positive” and “negative” refer to the class predicted or observed.
- False positives and false negatives are different errors. In medical screening, for example, a false negative may mean missing a disease, while a false positive may mean incorrectly flagging a healthy person.
- The positive class must be defined. In this lecture, positive means “hot dog,” but in other problems it could mean fraud, disease, or spam.
- Keep the label order consistent. When implementing the matrix in code, ensure the actual labels and predictions correspond to the same observations.
- Accuracy can be misleading on imbalanced datasets. A model can achieve high accuracy by predicting the majority class while missing many minority-class examples.

In the hot dog example, the confusion matrix tells us how often the model correctly identifies hot dogs, correctly rejects other foods, mistakenly labels other foods as hot dogs, or misses actual hot dogs.

# Machine Learning Foundations — The ROC Curve and ROC AUC

## 1. Overview of the Lecture

This lecture explains how to calculate the Receiver Operating Characteristic (ROC) curve and its associated metric, the Area Under the Curve (AUC), using a small binary classification example.

The main objectives are to understand:

1. How classification thresholds change model predictions.
2. How to identify true positives, true negatives, false positives, and false negatives.
3. How to calculate the True Positive Rate (TPR) and False Positive Rate (FPR).
4. How to plot ROC coordinates and construct the ROC curve.
5. How to interpret ROC AUC values.
6. How integration can calculate the area under the ROC curve.

The example uses four images and a model that predicts whether each image contains a hot dog.

## 2. Understand the Example Data

The model produces a score between 0 and 1 for each image. A higher score indicates a stronger prediction that the image contains a hot dog, assuming the score represents the estimated probability of the positive class.

The lecture uses the following example:

| Image | Actual label \\(Y\\) | Model score \\(\hat{Y}\\) |
| ----- | -------------------- | ------------------------- |
| A     | 1                    | 0.3                       |
| B     | 1                    | 0.5                       |

| D     | 0                    | 0.9                       |

Here:

- `1` means the image really contains a hot dog.
- `0` means the image does not contain a hot dog.
- The model score represents how strongly the model predicts the positive class.

The model's scores do not necessarily have to be calibrated probabilities for ROC analysis, but they must be usable to rank examples from more likely positive to less likely positive.

Example code:

## 3. Apply a Classification Threshold

A classification threshold converts a model score into a class prediction.

For this lecture, the rule is:

\\[ \hat{y} = \begin{cases} 1 & \text{if score} > \text{threshold}\\\ 0 & \text{if score} \leq \text{threshold} \end{cases} \\]

Notice that the lecture treats scores equal to the threshold as negative. This convention matters when a score is exactly 0.3, 0.5, or 0.6.

For example, at a threshold of 0.3:

- A score of 0.3 becomes negative.
- A score of 0.5 becomes positive.
- A score of 0.6 becomes positive.
- A score of 0.9 becomes positive.

Example code:

-------------------code----------------------
def classify(scores, threshold):
    return [
        1 if score > threshold else 0
        for score in scores
    ]


y_score = [0.3, 0.5, 0.6, 0.9]

for threshold in [0.3, 0.5, 0.6]:
    predictions = classify(y_score, threshold)
    print(f"Threshold {threshold}: {predictions}")

## 5. Calculate TPR and FPR

The ROC curve uses two rates derived from the confusion matrix.

### 5.1 True Positive Rate (TPR)

TPR measures the proportion of actual positive examples correctly identified.

\\[ TPR=\frac{TP}{TP+FN} \\]

A higher TPR means fewer actual positive examples are missed.

### 5.2 False Positive Rate (FPR)

FPR measures the proportion of actual negative examples incorrectly classified as positive.

\\[ FPR=\frac{FP}{FP+TN} \\]

A lower FPR means fewer actual negative examples are incorrectly flagged.

For the first threshold:

\\[ TPR=\frac{2}{2+0}=1.0 \\]

\\[ FPR=\frac{1}{1+1}=0.5 \\]

## 7. Calculate ROC AUC Using Integration

AUC is the area under the ROC curve. For this example, we connect the points with straight lines and use the trapezoidal rule.

For two adjacent points \\((x_1,y_1)\\) and \\((x_2,y_2)\\), the trapezoid area is

\\[ A=\frac{y_1+y_2}{2}(x_2-x_1) \\]

Here, \\(x\\) represents FPR and \\(y\\) represents TPR.

The ROC points in order are:

\\[ (0,0),\ (0,0.5),\ (0.5,0.5),\ (0.5,1),\ (1,1) \\]

Only segments with a positive horizontal width contribute area:

1\. From \\((0,0.5)\\) to \\((0.5,0.5)\\):

\\[ A_1=\frac{0.5+0.5}{2}(0.5-0)=0.25 \\]

2\. From \\((0.5,1)\\) to \\((1,1)\\):

\\[ A_2=\frac{1+1}{2}(1-0.5)=0.5 \\]

Therefore,

\\[ AUC=0.25+0.5=\boxed{0.75} \\]

# ROC points in increasing order of FPRroc_points = [    (0.0, 0.0),    (0.0, 0.5),    (0.5, 0.5),    (0.5, 1.0),    (1.0, 1.0),]auc = 0.0for i in range(1, len(roc_points)):    x1, y1 = roc_points[i - 1]    x2, y2 = roc_points[i]    # Trapezoidal rule    auc += ((y1 + y2) / 2) * (x2 - x1)print(f"ROC AUC: {auc:.2f}")

## 8. Interpret ROC AUC

| AUC value           | General interpretation                      |
| ------------------- | ------------------------------------------- |
| 0.5                 | Discrimination equivalent to random ranking |
| Between 0.5 and 1.0 | Better-than-random discrimination           |
| 1.0                 | Perfect discrimination                      |

AUC of 0.75 means the model has useful discriminative ability, but it is not perfect.

A common interpretation is that the model has a 75% probability of assigning a higher score to a randomly selected positive example than to a randomly selected negative example, with ties counted as half. This interpretation assumes the evaluation examples are representative of the population of interest.

Important: AUC does not tell you which classification threshold is best, and it does not guarantee that predicted probabilities are well calibrated.

## 9. Important Notes and Best Practices

- Be consistent with threshold rules. This lecture uses `score > threshold`; many libraries use `score >= threshold`. Equality matters when scores match a tested threshold.
- Check label-score alignment. Each score must belong to the corresponding actual label. Incorrect alignment changes the confusion matrix and AUC.
- Sort ROC points by FPR before integrating. The trapezoidal calculation assumes the points follow the curve from left to right.
- Include the ROC endpoints. The curve typically starts at \\((0,0)\\) and ends at \\((1,1)\\).
- AUC is a ranking metric. It evaluates discrimination across thresholds rather than performance at just one threshold.
- Do not rely on AUC alone. Depending on the problem, precision, recall, calibration, and the costs of false positives and false negatives may also matter.
- Small datasets give unstable estimates. Four examples are enough to demonstrate the calculation, but not enough to reliably evaluate a real-world model.

## 10. Summary

This lecture demonstrates how to build an ROC curve from classification scores and calculate its area.

1. Start with actual labels and model scores.
2. Apply several thresholds to turn scores into class predictions.
3. Count TP, TN, FP, and FN at each threshold.
4. Calculate TPR and FPR.
5. Plot each ROC point as \\((FPR,TPR)\\).
6. Add the endpoints and connect the points.
7. Calculate the area using integration, such as the trapezoidal rule.

For the example, the ROC AUC is 0.75. This summarizes the model's ability to rank positive examples above negative examples across thresholds.

## 11. Full Final Code

The following complete script reproduces the lecture's example, calculates the confusion matrix at each threshold, builds the ROC points, and computes AUC manually.

-------------------code----------------------
# ============================================================
# Machine Learning Foundations
# Topic: ROC Curve and ROC AUC
# ============================================================

# Step 1: Define actual labels and model scores
# 1 = hot dog, 0 = not a hot dog

y_actual = [0, 1, 0, 1]
y_score = [0.3, 0.5, 0.6, 0.9]

# Use the lecture's convention:
# score > threshold predicts positive.
thresholds = [0.3, 0.5, 0.6]


# Step 2: Define a function to calculate the confusion matrix

def confusion_counts(actual, predicted):
    if len(actual) != len(predicted):
        raise ValueError("Actual and predicted lengths must match.")

    TP = sum(
        a == 1 and p == 1
        for a, p in zip(actual, predicted)
    )
    TN = sum(
        a == 0 and p == 0
        for a, p in zip(actual, predicted)
    )
    FP = sum(
        a == 0 and p == 1
        for a, p in zip(actual, predicted)
    )
    FN = sum(
        a == 1 and p == 0
        for a, p in zip(actual, predicted)
    )

    return TP, FN, FP, TN


# Step 3: Evaluate the model at each threshold

roc_points = []

print("CONFUSION MATRIX AND ROC RATES")
print("--------------------------------")

for threshold in thresholds:
    predicted = [
        1 if score > threshold else 0
        for score in y_score
    ]

    TP, FN, FP, TN = confusion_counts(
        y_actual,
        predicted
    )

    # TPR and FPR require both actual classes to be present.
    positive_total = TP + FN
    negative_total = FP + TN

    if positive_total == 0 or negative_total == 0:
        raise ValueError(
            "TPR and FPR require positive and negative examples."
        )

    TPR = TP / positive_total
    FPR = FP / negative_total

    roc_points.append((FPR, TPR))

    print(f"\nThreshold: {threshold}")
    print(f"Predictions: {predicted}")
    print(f"TP={TP}, FN={FN}, FP={FP}, TN={TN}")
    print(f"TPR={TPR:.2f}, FPR={FPR:.2f}")


# Step 4: Add the ROC endpoints and sort points
# Remove duplicate coordinates so vertical or horizontal
# segments are not counted more than once.

roc_points.extend([
    (0.0, 0.0),
    (1.0, 1.0),
])

roc_points = sorted(set(roc_points), key=lambda point: point[0])

# If multiple points have the same FPR, sort by TPR.
roc_points.sort(key=lambda point: (point[0], point[1]))

print("\nROC POINTS")
print("----------")

for FPR, TPR in roc_points:
    print(f"(FPR={FPR:.2f}, TPR={TPR:.2f})")


# Step 5: Calculate AUC using the trapezoidal rule

auc = 0.0

for i in range(1, len(roc_points)):
    x1, y1 = roc_points[i - 1]
    x2, y2 = roc_points[i]

    width = x2 - x1
    average_height = (y1 + y2) / 2

    auc += width * average_height


# Step 6: Display the final result

print("\nFINAL RESULT")
print("------------")
print(f"ROC AUC = {auc:.2f}")

if auc == 0.5:
    print("The model has chance-level ranking performance.")
elif auc > 0.5:
    print("The model ranks positive examples better than chance.")
else:
    print("The model ranks positive examples worse than chance.")

*** 98. What Integral Calculus Is ***
# Integral Calculus: Introduction, Notation, and Applications to Machine Learning

## 1. What Is Integral Calculus?

Integral calculus is the branch of calculus concerned with accumulation, including calculating the area under a curve.

Previously, we studied differential calculus, which calculates the rate of change of a function. Integral calculus helps us determine the accumulated quantity from that rate of change.

For example, if we know how fast a car travels at every moment, integration allows us to calculate the total distance traveled.

### 1.1 Differential Calculus vs. Integral Calculus

| Concept                  | Differential calculus  | Integral calculus    |
| ------------------------ | ---------------------- | -------------------- |
| Main purpose             | Measure rate of change | Measure accumulation |
| Geometric interpretation | Slope of a curve       | Area under a curve   |
| Example                  | Distance → speed       | Speed → distance     |
| Main operation           | Differentiation        | Integration          |
| Symbol                   | \\(\frac{dy}{dx}\\)    | \\(\int f(x)\\,dx\\) |

### 1.2 Step-by-Step Example: Distance and Speed

Suppose a car travels at a constant speed of \\(60\\) km/h for \\(2\\) hours.

The distance is:

\\[ \text{Distance}=\text{Speed}\times\text{Time} \\]

\\[ d=60\times2=120\text{ km} \\]

Integration generalizes this calculation when the speed changes over time.

If speed is represented by \\(v(t)\\), then:

\\[ d=\int_0^2 v(t)\\,dt \\]

Here, the integral accumulates the speed over the two-hour interval to obtain the distance.

-------------------code----------------------
import sympy as sp

t = sp.symbols("t")

# Constant speed: 60 km/h
v = 60

# Integrate speed over 2 hours
distance = sp.integrate(v, (t, 0, 2))

print("Total distance:", distance, "km")
-------------------code----------------------

Expected output:

-------------------code----------------------
Total distance: 120 km
-------------------code----------------------

Important: Differentiation and integration are closely related inverse operations. Under appropriate conditions, integrating a derivative recovers the original function up to a constant.

## 2. Understanding the Area Under a Curve

A central idea in integral calculus is finding the area between a function's graph and the x-axis.

Consider the function:

\\[ f(x)=x^2 \\]

We want to find the area under this curve between \\(x=0\\) and \\(x=2\\).

### 2.1 Step 1: Approximate the Area Using Rectangles

One way to estimate the area is to divide the region into rectangles.

Each rectangle has:

- Width: \\(\Delta x\\), the width of a small interval.
- Height: A value of the function \\(f(x)\\).
- Area: Width multiplied by height.

\\[ A\_{\text{rectangle}}=\Delta x\cdot f(x) \\]

The approximate total area is the sum of the rectangle areas:

\\[ A\approx\sum\_{i=1}^{n}f(x_i^\*)\Delta x \\]

Here, \\(x_i^\*\\) is the point chosen to determine the height of rectangle \\(i\\).

### Python example

-------------------code----------------------
import numpy as np

def f(x):
    return x**2

a = 0
b = 2
n = 3

dx = (b - a) / n

# Use right endpoints for rectangle heights
x_values = np.linspace(a + dx, b, n)

area_approx = sum(f(x) * dx for x in x_values)

print("Rectangle width:", dx)
print("Approximate area:", area_approx)
-------------------code----------------------

The approximation is \\(3.1111\\), while the exact area is approximately \\(2.6667\\).

The difference occurs because rectangles do not perfectly match the curved boundary.

### 2.2 Step 2: Increase the Number of Rectangles

If we use more rectangles, each rectangle becomes narrower. The approximation generally improves for a continuous, well-behaved function when the rectangle heights are chosen appropriately.

For example:

- 3 rectangles: relatively rough approximation.
- 6 rectangles: a better approximation.
- 100 rectangles: usually much closer to the actual area.
- Infinitely many infinitesimally narrow rectangles: the exact integral, under suitable conditions.

-------------------code----------------------
import numpy as np

def f(x):
    return x**2

a, b = 0, 2

for n in [3, 6, 10, 100, 1000]:
    dx = (b - a) / n

    # Right-endpoint Riemann sum
    x_values = np.linspace(a + dx, b, n)

    area = sum(f(x) * dx for x in x_values)

    print(f"Rectangles: {n:4d} | Approximate area: {area:.6f}")
-------------------code----------------------

The exact area is:

\\[ \int_0^2 x^2\\,dx=\frac{8}{3}\approx2.666667 \\]

As the number of rectangles increases, the right-endpoint approximation approaches this value.

## 3. The Fundamental Idea: A Limit

Integral calculus works by taking the limit of increasingly accurate approximations.

For a function \\(f(x)\\), a definite integral can be defined using a limit of sums:

\\[ \int_a^b f(x)\\,dx = \lim\_{n\to\infty} \sum\_{i=1}^{n} f(x_i^\*)\Delta x \\]

where:

\\[ \Delta x=\frac{b-a}{n} \\]

- \\(a\\): lower integration limit.
- \\(b\\): upper integration limit.
- \\(n\\): number of subdivisions.
- \\(\Delta x\\): width of each subdivision.
- \\(f(x_i^\*)\\): height used for the rectangle.

As \\(n\\) increases, \\(\Delta x\\) approaches zero. Under suitable conditions, the sums converge to the exact area.

### Python example: Visualizing the rectangles

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

def f(x):
    return x**2

a, b = 0, 2
n = 6

dx = (b - a) / n
x = np.linspace(a, b, 400)

# Right endpoints
right_edges = np.linspace(a + dx, b, n)
heights = f(right_edges)

plt.figure(figsize=(8, 5))
plt.plot(x, f(x), label="f(x) = x²", linewidth=2)

plt.bar(
    right_edges - dx / 2,
    heights,
    width=dx,
    align="center",
    alpha=0.35,
    edgecolor="black",
    label="Rectangle approximation"
)

plt.xlabel("x")
plt.ylabel("f(x)")
plt.title("Approximating an Integral with Rectangles")
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
-------------------code----------------------

Best practice: Distinguish an approximation computed with a finite number of rectangles from the exact integral defined by a limit.

## 4. Integral Calculus Notation

The integral symbol is:

\\[ \int \\]

Its elongated, curved shape is commonly described as an S-shaped symbol.

The basic notation for an indefinite integral is:

\\[ \int f(x)\\,dx \\]

Each part has a specific meaning:

| Part       | Meaning                                             |
| ---------- | --------------------------------------------------- |
| \\(\int\\) | The integration operation                           |
| \\(f(x)\\) | The function being integrated, called the integrand |
| \\(dx\\)   | Indicates integration with respect to \\(x\\)       |

The variable following \\(d\\) tells us which variable we are integrating over.

### 4.1 Indefinite Integrals

An indefinite integral finds a family of antiderivatives. It does not specify a bounded interval.

For example:

\\[ \int x^2\\,dx=\frac{x^3}{3}+C \\]

Here, \\(C\\) is the integration constant because the derivative of any constant is zero.

### Python example

-------------------code----------------------
import sympy as sp

x = sp.symbols("x")

f = x**2

indefinite_integral = sp.integrate(f, x)

print(indefinite_integral)
-------------------code----------------------

Expected output:

-------------------code----------------------
x**3/3
-------------------code----------------------

SymPy omits the arbitrary constant \\(C\\) in its symbolic output. Mathematically, the complete indefinite integral includes \\(+C\\).

### 4.2 Definite Integrals

A definite integral specifies the interval over which accumulation is measured:

\\[ \int_a^b f(x)\\,dx \\]

- \\(a\\) is the lower limit.
- \\(b\\) is the upper limit.

For example:

\\[ \int_0^2 x^2\\,dx = \left[\frac{x^3}{3}\right]\_0^2 = \frac{8}{3} \\]

### Python example

-------------------code----------------------
import sympy as sp

x = sp.symbols("x")

f = x**2

definite_integral = sp.integrate(f, (x, 0, 2))

print("Exact area:", definite_integral)
print("Decimal area:", float(definite_integral))
-------------------code----------------------

Expected output:

-------------------code----------------------
Exact area: 8/3
Decimal area: 2.6666666666666665
-------------------code----------------------

## 5. Applications of Integral Calculus

Integral calculus has applications beyond calculating geometric areas.

### 5.1 Areas Under Curves in Machine Learning

A prominent example is the area under the Receiver Operating Characteristic curve, known as ROC AUC.

- The ROC curve plots the true-positive rate against the false-positive rate at different classification thresholds.
- AUC summarizes the classifier's ability to rank positive examples above negative examples.
- AUC is calculated by integrating the ROC curve, often numerically.

For a ROC curve \\(TPR(FPR)\\):

\\[ AUC=\int_0^1 TPR(FPR)\\,d(FPR) \\]

This is useful because it summarizes discrimination across thresholds instead of evaluating a model at only one threshold.

### Python example

-------------------code----------------------
import numpy as np
from sklearn.metrics import auc

fpr = np.array([0.0, 0.1, 0.3, 0.6, 1.0])
tpr = np.array([0.0, 0.6, 0.8, 0.9, 1.0])

roc_auc = auc(fpr, tpr)

print(f"ROC AUC: {roc_auc:.3f}")
-------------------code----------------------

This example uses illustrative ROC coordinates, not a trained model's measured performance.

### 5.2 Expectation of a Random Variable

Another important application is probability theory.

For a continuous random variable \\(X\\) with probability density function \\(p(x)\\), its expected value is:

\\[ E[X]=\int\_{-\infty}^{\infty}x\\,p(x)\\,dx \\]

This integral calculates a probability-weighted average over possible values.

Expectations are widely used in machine learning, including probabilistic modeling, statistical learning, and deep learning. The lecture identifies this topic as a subject to be covered in the upcoming probability and information theory section.

### Python example

Suppose \\(X\\) is uniformly distributed between 0 and 1. Its density is \\(p(x)=1\\) on that interval.

\\[ E[X]=\int_0^1 x\\,dx=\frac12 \\]

-------------------code----------------------
import sympy as sp

-------------------code----------------------

-------------------code----------------------

-------------------code----------------------

### 5.3 Other Applications

Integral calculus can also be used to calculate:

- Volumes of three-dimensional objects.
- Centers of mass and other central points.
- Total quantities accumulated from changing rates.
- Probabilities and expected values in continuous probability distributions.

## 6. Important Notes and Best Practices

1. Differentiate versus integrate: Differentiation measures instantaneous change; integration accumulates quantities.
2. Interpret the units: If speed is measured in kilometers per hour and time in hours, integrating speed over time produces kilometers.
3. Understand the limits: Definite integrals use lower and upper limits; indefinite integrals do not.
4. Include the integration constant: An indefinite integral requires \\(+C\\).
5. Do not confuse approximation with exact integration: A finite rectangle sum estimates the area, while the definite integral represents the limit under appropriate conditions.
6. Use numerical methods when needed: Complex integrals may not have convenient symbolic solutions, so numerical integration can be useful.
7. Interpret AUC correctly: ROC AUC measures ranking discrimination, not classification accuracy at a particular threshold.
8. Check the function and interval: A definite integral can represent signed area. If a function falls below the x-axis, its contribution is negative; geometric area may require a different calculation.

## 7. Summary

Integral calculus studies accumulation and the area under curves. It complements differential calculus: differentiation measures rates of change, while integration can recover accumulated quantities from those rates.

The key idea is to approximate the area using many narrow rectangles. As their widths approach zero, the sums converge to an integral under suitable conditions.

The main notation is:

\\[ \int f(x)\\,dx \\]

For an indefinite integral, we find an antiderivative and include the constant \\(C\\). A definite integral adds lower and upper limits to calculate accumulation over an interval.

In machine learning, important applications include ROC AUC and expectations in probability theory, as well as other accumulated quantities.

# Lecture Notes: Three Fundamental Rules of Integration

## 1. Introduction to Integration

Integration is the reverse process of differentiation. While differentiation measures the rate of change of a function, integration helps us recover the original function or calculate accumulated quantities.

For example, if:

\\[ f(x)=x^4 \\]

Differentiation gives:

\\[ \frac{d}{dx}x^4=4x^3 \\]

Integration works in the opposite direction:

\\[ \int 4x^3\\,dx=x^4+C \\]

The \\(C\\) represents an arbitrary constant, which is necessary because the derivative of any constant is zero.

This lecture covers three fundamental integration rules:

1. The power rule
2. The constant multiple rule
3. The sum rule

## 2. Rule One: The Power Rule

The power rule is used to integrate a variable raised to a power.

### 2.1 Formula

For any real exponent \\(n\neq -1\\):

\\[ \boxed{\int x^n\\,dx=\frac{x^{n+1}}{n+1}+C} \\]

The steps are:

1. Add \\(1\\) to the exponent.
2. Divide by the new exponent.
3. Add the constant of integration \\(C\\).

### 2.2 Step-by-step example

Integrate:

\\[ \int x^4\\,dx \\]

Step 1: Add \\(1\\) to the exponent.

\\[ 4+1=5 \\]

Step 2: Divide by the new exponent.

\\[ \frac{x^5}{5} \\]

Step 3: Add the constant of integration.

\\[ \boxed{\int x^4\\,dx=\frac{x^5}{5}+C} \\]

### 2.3 Python example

We can define the original function and its antiderivative in Python.

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Original function
def f(x):
    return x**4

# Antiderivative using the power rule
def F(x):
    return x**5 / 5

x = np.linspace(0, 2, 100)

plt.plot(x, f(x), label="f(x) = x^4")
plt.plot(x, F(x), label="F(x) = x^5 / 5")
plt.xlabel("x")
plt.ylabel("y")
plt.title("Power Rule of Integration")
plt.grid(True)
plt.legend()
plt.show()
-------------------code----------------------

The function `F(x)` is an antiderivative of `f(x)` because differentiating \\(x^5/5\\) gives \\(x^4\\).

### 2.4 Important limitation: The exponent \\(-1\\)

The power rule cannot be applied directly when \\(n=-1\\), because the denominator becomes zero:

\\[ \frac{x^{-1+1}}{-1+1}=\frac{x^0}{0} \\]

Division by zero is undefined.

Instead, use the special rule:

\\[ \boxed{\int \frac{1}{x}\\,dx=\ln|x|+C} \\]

This formula applies on intervals where \\(x\neq 0\\).

## 3. Rule Two: The Constant Multiple Rule

The constant multiple rule applies when a function is multiplied by a constant.

### 3.1 Formula

If \\(a\\) is a constant, then:

\\[ \boxed{\int a f(x)\\,dx=a\int f(x)\\,dx} \\]

In simple terms:

1. Keep the constant outside the integral.
2. Integrate the remaining function.
3. Multiply by the original constant.
4. Include \\(C\\).

### 3.2 Step-by-step example

Integrate:

\\[ \int 9x^2\\,dx \\]

Step 1: Move the constant \\(9\\) outside the integral.

\\[ 9\int x^2\\,dx \\]

Step 2: Apply the power rule.

\\[ 9\left(\frac{x^3}{3}\right)+C \\]

Step 3: Simplify.

\\[ \boxed{\int 9x^2\\,dx=3x^3+C} \\]

### 3.3 Python example

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Original function
def f(x):
    return 9 * x**2

# Antiderivative
def F(x):
    return 3 * x**3

x = np.linspace(0, 2, 100)

plt.plot(x, f(x), label="f(x) = 9x²")
plt.plot(x, F(x), label="F(x) = 3x³")
plt.xlabel("x")
plt.ylabel("y")
plt.title("Constant Multiple Rule")
plt.grid(True)
plt.legend()
plt.show()
-------------------code----------------------

To verify the answer, differentiate \\(3x^3\\):

\\[ \frac{d}{dx}(3x^3)=9x^2 \\]

This recovers the original function.

## 4. Rule Three: The Sum Rule

The sum rule allows us to integrate a sum of separate terms individually.

### 4.1 Formula

\\[ \boxed{\int [f(x)+g(x)]\\,dx =\int f(x)\\,dx+\int g(x)\\,dx} \\]

The same principle applies to subtraction:

\\[ \int [f(x)-g(x)]\\,dx =\int f(x)\\,dx-\int g(x)\\,dx \\]

### 4.2 Step-by-step example

Integrate:

\\[ \int (x^4+9x^2)\\,dx \\]

Step 1: Separate the terms.

\\[ \int x^4\\,dx+\int 9x^2\\,dx \\]

Step 2: Integrate the first term using the power rule.

\\[ \int x^4\\,dx=\frac{x^5}{5} \\]

Step 3: Integrate the second term using the constant multiple rule and power rule.

\\[ \int 9x^2\\,dx=3x^3 \\]

Step 4: Combine the results and add the constant.

\\[ \boxed{\int (x^4+9x^2)\\,dx =\frac{x^5}{5}+3x^3+C} \\]

### 4.3 Python example

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Original function
def f(x):
    return x**4 + 9 * x**2

# Antiderivative
def F(x):
    return x**5 / 5 + 3 * x**3

x = np.linspace(0, 2, 100)

plt.plot(x, f(x), label="f(x) = x⁴ + 9x²")
plt.plot(x, F(x), label="F(x) = x⁵/5 + 3x³")
plt.xlabel("x")
plt.ylabel("y")
plt.title("Sum Rule of Integration")
plt.grid(True)
plt.legend()
plt.show()
-------------------code----------------------

## 5. Verify Integration by Differentiation

A reliable way to check an indefinite integral is to differentiate your answer. You should recover the original integrand.

For example:

\\[ F(x)=\frac{x^5}{5}+3x^3+C \\]

Differentiate each term:

\\[ F'(x)=x^4+9x^2+0 \\]

Therefore:

\\[ \boxed{F'(x)=x^4+9x^2} \\]

The result matches the original function.

### Python verification

We can check the formulas numerically by approximating the derivative with finite differences.

-------------------code----------------------
import numpy as np

def f(x):
    return x**4 + 9 * x**2

def F(x):
    return x**5 / 5 + 3 * x**3

# Test points
x_values = np.array([0.5, 1.0, 1.5, 2.0])

# Small step for numerical differentiation
h = 1e-5

for x in x_values:
    numerical_derivative = (F(x + h) - F(x - h)) / (2 * h)
    original_value = f(x)

    print(f"x = {x:.1f}")
    print(f"Original function:      {original_value:.6f}")
    print(f"Numerical derivative:   {numerical_derivative:.6f}")
    print()
-------------------code----------------------

The numerical derivative should be very close to the original function's value. Small differences occur because of floating-point arithmetic and the finite approximation step.

## 6. Important Notes and Best Practices

### 6.1 Always include the constant \\(C\\)

For indefinite integrals, include \\(+C\\):

\\[ \int x^2\\,dx=\frac{x^3}{3}+C \\]

This is necessary because differentiation removes constants.

### 6.2 Do not confuse differentiation and integration

| Operation       | Power rule                                                        |
| --------------- | ----------------------------------------------------------------- |
| Differentiation | Multiply by the exponent, then subtract \\(1\\) from the exponent |
| Integration     | Add \\(1\\) to the exponent, then divide by the new exponent      |

For example:

\\[ \frac{d}{dx}x^4=4x^3 \\]

\\[ \int x^3\\,dx=\frac{x^4}{4}+C \\]

### 6.3 Apply the rules together

Many expressions require more than one rule. For example:

\\[ \int (5x^3+2x)\\,dx \\]

Separate the terms, apply the constant multiple rule, and then apply the power rule:

\\[ =\frac{5x^4}{4}+x^2+C \\]

### 6.4 Remember the exception

The standard power rule requires \\(n\neq -1\\). For \\(x^{-1}=1/x\\), use the logarithm rule instead.

### 6.5 Use Python appropriately

Python can help you plot functions, test calculations, and approximate derivatives or integrals. However, the mathematical rules determine the exact symbolic result. For these examples, NumPy and Matplotlib are sufficient; SciPy is not required.

# Lecture Notes: Definite Integrals

## 1. Introduction to Definite Integrals

In previous lessons, we studied indefinite integrals, which find an antiderivative of a function. This lecture introduces definite integrals, which calculate the accumulated value of a function over a specific interval.

For a function \\(f(x)\\), a definite integral is written as:

\\[ \boxed{\int_a^b f(x)\\,dx} \\]

Each part has a specific meaning:

- \\(f(x)\\): the function being integrated.
- \\(dx\\): indicates that we integrate with respect to \\(x\\).
- \\(a\\): the lower limit of integration.
- \\(b\\): the upper limit of integration.

The limits \\(a\\) and \\(b\\) define the interval over which we calculate the integral.

### 1.1 Indefinite vs. definite integrals

| Indefinite integral                        | Definite integral                                                      |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| Finds an antiderivative                    | Evaluates accumulated value over an interval                           |
| Has no limits                              | Has lower and upper limits                                             |
| Includes the constant \\(C\\)              | Produces a numerical result; no \\(+C\\) is needed in the final answer |
| Example: \\(\int x\\,dx=\frac{x^2}{2}+C\\) | Example: \\(\int_1^2 x\\,dx=\frac{3}{2}\\)                             |

Important: A definite integral represents signed area. When the function is above the \\(x\\)-axis, its contribution is positive; when it is below the \\(x\\)-axis, its contribution is negative. In this lecture's example, the function stays above the \\(x\\)-axis, so the integral equals the ordinary area under the curve.

## 2. The Example: \\(y=\frac{x}{2}\\)

We want to calculate the area under the line

\\[ f(x)=\frac{x}{2} \\]

between \\(x=1\\) and \\(x=2\\).

The required integral is:

\\[ \boxed{\int_1^2 \frac{x}{2}\\,dx} \\]

This represents the area between the graph and the \\(x\\)-axis, from \\(x=1\\) to \\(x=2\\).

We can calculate this using the Fundamental Theorem of Calculus.

## 3. Step 1: Find the Indefinite Integral

The first step in evaluating a definite integral is to find the antiderivative of the function.

Start with:

\\[ \int \frac{x}{2}\\,dx \\]

### 3.1 Apply the constant multiple rule

Move the constant \\(\frac12\\) outside the integral:

\\[ \int \frac{x}{2}\\,dx =\frac12\int x\\,dx \\]

### 3.2 Apply the power rule

Recall the power rule:

\\[ \int x^n\\,dx=\frac{x^{n+1}}{n+1}+C \\]

Since \\(x=x^1\\):

\\[ \int x\\,dx=\frac{x^2}{2}+C \\]

Substitute this result:

\\[ \frac12\left(\frac{x^2}{2}\right)+C \\]

### 3.3 Simplify

Multiply the two fractions:

\\[ \boxed{F(x)=\frac{x^2}{4}+C} \\]

This is the indefinite integral of \\(x/2\\).

### Python code for Step 1

-------------------code----------------------
def antiderivative(x):
    return x**2 / 4

# Example: evaluate the antiderivative at x = 1
print(antiderivative(1))  # 0.25
-------------------code----------------------

The Python function returns the antiderivative with \\(C=0\\). We do not need to explicitly include \\(C\\) when computing the definite integral because the constant cancels when we subtract the endpoint values.

## 4. Step 2: Evaluate the Antiderivative at the Lower Limit

The lower limit is \\(x=1\\).

Substitute \\(x=1\\) into the antiderivative:

\\[ F(1)=\frac{1^2}{4} \\]

Since \\(1^2=1\\):

\\[ \boxed{F(1)=\frac14} \\]

This is the value of the antiderivative at the lower boundary.

### Python code for Step 2

-------------------code----------------------

print("F(1) =", lower_value)
-------------------code----------------------

Output:

-------------------code----------------------

-------------------code----------------------

## 5. Step 3: Evaluate the Antiderivative at the Upper Limit

The upper limit is \\(x=2\\).

Substitute \\(x=2\\):

\\[ F(2)=\frac{2^2}{4} \\]

Since \\(2^2=4\\):

\\[ \boxed{F(2)=1} \\]

### Python code for Step 3

-------------------code----------------------
upper_limit = 2

upper_value = antiderivative(upper_limit)

print("F(2) =", upper_value)
-------------------code----------------------

Output:

-------------------code----------------------
F(2) = 1.0
-------------------code----------------------

## 6. Step 4: Subtract the Lower Value from the Upper Value

The Fundamental Theorem of Calculus states that if \\(F'(x)=f(x)\\), then:

\\[ \boxed{\int_a^b f(x)\\,dx=F(b)-F(a)} \\]

In other words:

1. Find the antiderivative.
2. Evaluate it at the upper limit.
3. Evaluate it at the lower limit.
4. Subtract the lower value from the upper value.

For our example:

\\[ \int_1^2 \frac{x}{2}\\,dx=F(2)-F(1) \\]

Substitute the values:

\\[ =1-\frac14 \\]

Therefore:

\\[ \boxed{\int_1^2 \frac{x}{2}\\,dx=\frac34=0.75} \\]

The area under the curve between \\(x=1\\) and \\(x=2\\) is 0.75 square units.

### 6.1 Why does the constant \\(C\\) disappear?

If we keep the constant in the antiderivative, the calculation becomes:

\\[ \left(1+C\right)-\left(\frac14+C\right) \\]

Expanding the subtraction:

\\[ 1+C-\frac14-C \\]

The constants cancel:

\\[ C-C=0 \\]

Leaving:

\\[ 1-\frac14=\frac34 \\]

This explains why the final result of a definite integral does not require \\(+C\\).

### Python code for Step 4

-------------------code----------------------
lower_limit = 1
upper_limit = 2

area = (
    antiderivative(upper_limit)
    - antiderivative(lower_limit)
)

print("Definite integral =", area)
-------------------code----------------------

Output:

-------------------code----------------------
Definite integral = 0.75
-------------------code----------------------

## 8. Important Notes and Best Practices

1. Always find the antiderivative first. Use the integration rules you learned in previous lessons.
2. Subtract in the correct order. Always calculate \\(F(b)-F(a)\\), meaning upper limit minus lower limit.
3. Do not include \\(+C\\) in the final definite integral. The constants cancel when you subtract the endpoint values.
4. Distinguish signed area from geometric area. If a function crosses below the \\(x\\)-axis, the definite integral can be negative or can combine positive and negative contributions. To calculate total geometric area, you may need to split the interval or integrate the absolute value.
5. Use Python to verify your calculations. For a simple function, the antiderivative method gives the exact mathematical result, while numerical methods may produce approximations.

# Lecture Notes: Solving Definite Integrals Manually and with Python

## 1. Learning Objectives

In this lecture, we learn how to calculate the same definite integral using two different approaches:

1. Symbolic integration: Solve the integral manually using mathematical rules.
2. Numerical integration: Use Python and SciPy to calculate the integral computationally.

We will solve:

\\[ \int_3^4 2x\\,dx \\]

Both methods should produce the same result.

## 2. Understanding the Problem

We are given the function:

\\[ f(x)=2x \\]

We want to calculate its definite integral over the interval from 3 to 4:

\\[ \int_3^4 2x\\,dx \\]

A definite integral calculates the accumulated value of a function over a specified interval.

In this example, it represents the area under the curve \\(f(x)=2x\\), between \\(x=3\\) and \\(x=4\\).

## 3. Method 1: Symbolic Integration (Manual Calculation)

To calculate a definite integral manually, we first find its indefinite integral and then evaluate it at the interval boundaries.

### 3.1 Step 1: Apply the Constant Multiple Rule

Our integral is:

\\[ \int 2x\\,dx \\]

According to the constant multiple rule:

\\[ \int a f(x)\\,dx=a\int f(x)\\,dx \\]

We can move the constant 2 outside the integral:

\\[ =2\int x\\,dx \\]

### 3.2 Step 2: Apply the Power Rule

The power rule is:

\\[ \int x^n\\,dx=\frac{x^{n+1}}{n+1}+C \\]

For our function, \\(x=x^1\\), so \\(n=1\\):

\\[ \int x\\,dx=\frac{x^2}{2}+C \\]

Substitute this into our expression:

\\[ 2\left(\frac{x^2}{2}\right)+C \\]

Cancel the two:

\\[ F(x)=x^2+C \\]

This is our indefinite integral (antiderivative).

### 3.3 Step 3: Evaluate the Upper and Lower Limits

The fundamental theorem of calculus tells us:

\\[ \int_a^b f(x)\\,dx=F(b)-F(a) \\]

For our example:

- Lower limit: \\(a=3\\)
- Upper limit: \\(b=4\\)
- Antiderivative: \\(F(x)=x^2+C\\)

First, evaluate the upper limit:

\\[ F(4)=4^2+C=16+C \\]

Next, evaluate the lower limit:

\\[ F(3)=3^2+C=9+C \\]

### 3.4 Step 4: Subtract the Results

Now subtract the lower-limit result from the upper-limit result:

\\[ F(4)-F(3) \\]

\\[ =(16+C)-(9+C) \\]

The constants cancel:

\\[ =16-9 \\]

Final result: 7

\\[ \boxed{\int_3^4 2x\\,dx=7} \\]

Important: The integration constant \\(C\\) disappears when calculating a definite integral because it is present in both evaluations.

## 5. Understanding the Two Approaches

Both methods calculate the same mathematical quantity, but they work differently.

| Feature                   | Symbolic integration | Numerical integration   |
| ------------------------- | -------------------- | ----------------------- |
| Approach                  | Mathematical rules   | Numerical algorithms    |
| Result                    | Exact expression     | Numerical approximation |
| Requires Python           | No                   | Yes                     |
| Handles complex functions | Sometimes difficult  | Often practical         |

### Why are both methods useful?

Symbolic integration:

- Helps us understand mathematical relationships.
- Can produce exact solutions.
- Useful for functions with manageable antiderivatives.

Numerical integration:

- Useful when finding an exact antiderivative is difficult or impossible.
- Can handle many complicated functions.
- Widely used in scientific computing and machine learning.

## 7. Important Notes and Best Practices

1. Always identify the integration limits. The lower and upper limits determine the interval over which the function is integrated.
2. Find the antiderivative first when solving manually. For a definite integral, calculate \\(F(b)-F(a)\\).
3. Remember the integration constant. Include \\(+C\\) when finding an indefinite integral, even though it cancels in a definite integral.
4. Understand the output of `quad()`. It returns a tuple containing the integral approximation and estimated absolute error.
5. Do not confuse numerical error with the actual integral. A very small estimated error indicates that the numerical calculation is highly accurate according to the algorithm's error estimate.
6. Use numerical integration when symbolic integration is impractical. This is especially useful in scientific computing and machine learning.
7. Check your Python environment. The SciPy import issue encountered in your macOS environment is a dependency/binary-loading problem, not an error in the integration formula or Python code.
