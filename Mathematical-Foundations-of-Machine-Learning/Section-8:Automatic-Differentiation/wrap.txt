# 3. Segment 2 — Derivatives and Differentiation

The second segment focused on **computing derivatives**.

## 3.1 The Delta Method

Initially, derivatives were calculated using the **Delta method**.

The basic idea was:

-------------------code----------------------
Two points on a curve
        ↓
Calculate Δy / Δx
        ↓
Make Δx smaller and smaller
        ↓
Δx → 0
        ↓
Slope approaches the derivative
-------------------code----------------------

The Delta method therefore connected our previous understanding of limits with derivatives.

---

## 3.2 Differentiation Rules

After developing an understanding of derivatives using the Delta method, we learned a collection of rules that allow derivatives to be calculated much more quickly.

The rules covered included:

* Constant rule
* Power rule
* Constant multiple rule
* Sum rule
* Product rule
* Quotient rule
* Chain rule
* Power rule on a function chain

These rules allow us to differentiate increasingly complicated mathematical expressions without repeatedly going back to the Delta method.

# 4. Why Segment 2 Leads Into Segment 3

Everything learned so far provides the foundation for **automatic differentiation**.

Previously, we calculated derivatives:

-------------------code----------------------
By hand
   ↓
Using mathematical rules
   ↓

-------------------code----------------------

But machine learning frequently involves extremely large and complicated mathematical expressions.

For example, a neural network can contain many layers, with each layer effectively forming part of a large chain of functions.

Doing all of these derivatives manually would be impractical.

This creates the motivation for **automatic differentiation**.

# 6. Automatic Differentiation With PyTorch

One of the first topics in this segment will be implementing automatic differentiation using **PyTorch**.

The lecture specifically says that we will study automatic differentiation in the **PyTorch library**.

The goal is to move from manually calculating derivatives to letting a machine-learning framework perform the calculations computationally.

A basic conceptual example can be represented as:

-------------------code----------------------python
import torch

x = torch.tensor(2.0, requires_grad=True)

y = x ** 2

y.backward()

print(x.grad)
-------------------code----------------------

The important idea here is that PyTorch tracks the computation involving `x` and can calculate the derivative automatically.

For:

[
y=x^2
]

the derivative is:

[
\frac{dy}{dx}=2x
]

so at (x=2):

-------------------code----------------------
dy/dx = 4
-------------------code----------------------

Note: the lecture excerpt itself only introduces that PyTorch automatic differentiation will be covered; the code above is a simple illustrative implementation, not code presented in the lecture.

# 13. Full Final Code

Because this lecture is primarily a **roadmap/introduction** to automatic differentiation and does not provide a complete coding exercise, there is no official final code from the lecture itself.

For reference, the following is a small illustrative PyTorch example showing the basic idea of automatic differentiation:

-------------------code----------------------python
import torch

# Create a variable and tell PyTorch to track its derivatives
x = torch.tensor(2.0, requires_grad=True)

# Define a function
y = x ** 2

# Calculate the derivative automatically
y.backward()

# Display dy/dx
print(x.grad)
-------------------code----------------------

Output:

-------------------code----------------------
tensor(4.)
-------------------code----------------------

This corresponds to:

[
y=x^2
]

and:

[
\frac{dy}{dx}=2x
]

At (x=2):

[
\frac{dy}{dx}=4
]

Again, this code is **illustrative rather than code supplied in the lecture**.
