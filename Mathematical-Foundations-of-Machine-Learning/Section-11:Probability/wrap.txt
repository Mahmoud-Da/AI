## 4. Segment One: Introduction to Probability

This is the largest segment and covers the essential concepts needed to understand probability theory.

### 4.1 What Is Probability Theory?

Probability theory is the mathematical study of uncertainty and random events.

It allows us to quantify how likely an event is to happen.

A probability is represented by a number between 0 and 1:

\\[ 0\leq P(A)\leq 1 \\]

Where:

- \\(P(A)=0\\): The event is impossible.
- \\(P(A)=1\\): The event is certain.
- \\(P(A)=0.5\\): The event has a 50% probability.

Example: A fair coin has two possible outcomes.

\\[ P(\text{Heads})=0.5 \\]

\\[ P(\text{Tails})=0.5 \\]

Python example:

-------------------code----------------------
# Probability of getting heads or tails
p_heads = 0.5
p_tails = 0.5

print("Probability of heads:", p_heads)
print("Probability of tails:", p_tails)

print("Total probability:", p_heads + p_tails)
-------------------code----------------------

Output:

-------------------code----------------------
Probability of heads: 0.5
Probability of tails: 0.5
Total probability: 1.0
-------------------code----------------------

### 4.2 Frequentist vs. Bayesian Probability

The instructor introduces two major interpretations of probability.

Frequentist approach

Probability is interpreted as the long-run relative frequency of an event when an experiment is repeated many times under the same conditions.

Example: If a fair coin is flipped many times, approximately 50% of the results should be heads.

Bayesian approach

Probability represents uncertainty or belief about an event, given the available information. These beliefs can be updated when new evidence becomes available.

Example: You believe an email has a 70% probability of being spam. After examining its content, you update that probability.

| Approach    | Main idea                               |
| ----------- | --------------------------------------- |
| Frequentist | Long-run frequency of repeated events   |
| Bayesian    | Degree of belief updated using evidence |

Both approaches are important in statistics and machine learning.

### 4.3 Applications of Probability in Machine Learning

Probability is useful in many machine learning applications:

- Classification: estimating the probability that an observation belongs to a class.
- Regression with uncertainty: estimating uncertainty around predictions.
- Natural Language Processing: estimating probabilities of words or sequences.
- Recommendation Systems: estimating the likelihood that a user will interact with an item.
- Bayesian Machine Learning: updating beliefs using observed data.

## 5. Random Variables

The instructor identifies random variables as one of the most important concepts in probability theory.

For example, when rolling a six-sided die, we can define a random variable \\(X\\) representing the number that appears.

\\[ X\in\\{1,2,3,4,5,6\\} \\]

## 6. Probability Mass Functions and Probability Density Functions

These functions describe probability distributions.

### 6.1 Probability Mass Function (PMF)

A PMF describes the probability of each possible value of a discrete random variable.

For a fair six-sided die:

\\[ P(X=x)=\frac16 \\]

for \\(x\in\\{1,2,3,4,5,6\\}\\).

Python example:

-------------------code----------------------
# Probability distribution of a fair six-sided die
values = [1, 2, 3, 4, 5, 6]

probabilities = [1/6] * 6

for value, probability in zip(values, probabilities):
    print(f"P(X = {value}) = {probability:.4f}")
-------------------code----------------------

### 6.2 Probability Density Function (PDF)

A PDF describes the density of a continuous random variable.

Unlike a PMF, the PDF does not directly give the probability of one exact value.

Instead, probabilities are calculated over intervals by integrating the density function:

\\[ P(a\leq X\leq b)=\int_a^b f(x)\\,dx \\]

For example, a normal distribution has a bell-shaped probability density curve.

Python example:

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# Generate values along the horizontal axis
x = np.linspace(-4, 4, 500)

# Calculate the standard normal PDF
pdf = norm.pdf(x, loc=0, scale=1)

plt.plot(x, pdf)
plt.title("Standard Normal Distribution")
plt.xlabel("Value")
plt.ylabel("Probability Density")
plt.show()
-------------------code----------------------

## 7. Expected Value

Expected value represents the theoretical average outcome of a random variable over many repetitions.

For a discrete random variable:

\\[ E[X]=\sum_x xP(X=x) \\]

For example, the expected value of a fair six-sided die is:

\\[ E[X]=\frac{1+2+3+4+5+6}{6}=3.5 \\]

Python example:

-------------------code----------------------
values = [1, 2, 3, 4, 5, 6]

probabilities = [1/6] * 6

expected_value = sum(
    value * probability
    for value, probability in zip(values, probabilities)
)

print("Expected value:", expected_value)
-------------------code----------------------

Output:

-------------------code----------------------
Expected value: 3.5
-------------------code----------------------

An expected value does not need to be a possible outcome. In this example, a die cannot show 3.5, but its theoretical average is 3.5.

## 8. Measuring Probability Distributions

The lecture introduces several ways to summarize and understand a probability distribution.

### 8.1 Measures of Central Tendency

These measures describe the center of a dataset or distribution.

Mean

The arithmetic average:

\\[ \bar{x}=\frac{1}{n}\sum\_{i=1}^{n}x_i \\]

Median

The middle value after sorting the observations.

Mode

The most frequently occurring value.

Python example:

-------------------code----------------------
import numpy as np
from scipy import stats

data = [2, 3, 3, 4, 5, 6, 7]

mean = np.mean(data)
median = np.median(data)
mode = stats.mode(data, keepdims=False).mode

print("Mean:", mean)
print("Median:", median)
print("Mode:", mode)
-------------------code----------------------

### 8.2 Quantiles

Quantiles divide an ordered dataset into portions.

The main types are:

- Quartiles: Divide data into four parts.
- Deciles: Divide data into ten parts.
- Percentiles: Divide data into one hundred parts.

For example, the 50th percentile corresponds to the median.

Python example:

-------------------code----------------------
import numpy as np

data = [10, 20, 30, 40, 50, 60, 70, 80, 90]

quartiles = np.percentile(data, [25, 50, 75])

print("Q1:", quartiles[0])
print("Q2:", quartiles[1])
print("Q3:", quartiles[2])
-------------------code----------------------

## 9. Measuring Dispersion

Central tendency describes the center of a distribution, but it does not explain how spread out the observations are.

Dispersion measures describe how much the data vary.

### 9.1 Variance

Variance measures the average squared deviation from the mean.

Population variance:

\\[ \sigma^2=\frac{1}{N}\sum\_{i=1}^{N}(x_i-\mu)^2 \\]

### 9.2 Standard Deviation

Standard deviation is the square root of variance:

\\[ \sigma=\sqrt{\sigma^2} \\]

It measures spread in the same units as the original data.

### 9.3 Standard Error

Standard error measures the variability of a sample statistic, such as the sample mean, across repeated samples.

For the sample mean:

\\[ SE=\frac{s}{\sqrt{n}} \\]

Where:

- \\(s\\): Sample standard deviation.
- \\(n\\): Sample size.

Python example:

-------------------code----------------------
import numpy as np

data = [10, 12, 14, 16, 18, 20]

variance = np.var(data, ddof=1)
standard_deviation = np.std(data, ddof=1)

standard_error = standard_deviation / np.sqrt(len(data))

print("Sample variance:", variance)
print("Sample standard deviation:", standard_deviation)
print("Standard error:", standard_error)
-------------------code----------------------

## 10. Comparing Different Distributions

After learning how to describe individual distributions, the course moves on to understanding relationships between different variables.

### 10.1 Covariance

Covariance measures how two variables vary together.

- Positive covariance: The variables tend to increase together.
- Negative covariance: One tends to increase when the other decreases.
- Near-zero covariance: No strong linear co-movement is indicated.

### 10.2 Correlation

Correlation measures the strength and direction of a linear relationship between two variables.

The Pearson correlation coefficient ranges from -1 to +1.

| Correlation | Interpretation                       |
| ----------- | ------------------------------------ |
| +1          | Perfect positive linear relationship |
| 0           | No linear correlation                |
| -1          | Perfect negative linear relationship |

Python example:

-------------------code----------------------
import numpy as np

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

correlation = np.corrcoef(x, y)[0, 1]

print("Correlation:", correlation)
-------------------code----------------------

-------------------code----------------------
Correlation: 1.0

## 11. Advanced Probability Concepts

The instructor also introduces several more advanced topics that will be covered later in the course.

### 11.1 Marginal Probability

Marginal probability is the probability of one event without specifying the outcome of another variable.

Example:

\\[ P(A) \\]

### 11.2 Conditional Probability

Conditional probability is the probability of an event occurring given that another event has already occurred.

\\[ P(A\mid B)=\frac{P(A\cap B)}{P(B)} \\]

Provided that \\(P(B)>0\\).

### 11.3 Independence

Two events are independent if knowing that one event occurred does not change the probability of the other.

\\[ P(A\cap B)=P(A)P(B) \\]

### 11.4 Conditional Independence

Two variables are conditionally independent given a third variable if they become independent once that third variable is known.

This concept is especially important in probabilistic graphical models and Bayesian networks.

### 11.5 Bayes' Rule

Bayes' rule describes how to update the probability of a hypothesis when new evidence becomes available.

\\[ P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)} \\]

Where:

- \\(P(A)\\): Prior probability.
- \\(P(B\mid A)\\): Likelihood.
- \\(P(B)\\): Evidence.
- \\(P(A\mid B)\\): Posterior probability.

Bayes' rule is fundamental to Bayesian statistics and many machine learning applications.

## 12. Important Notes and Best Practices

1. Understand random variables first. They are the foundation for probability distributions and expected values.
2. Distinguish discrete and continuous variables. PMFs describe discrete probabilities, while PDFs describe continuous probability densities.
3. Do not confuse probability density with probability. For a continuous variable, probability comes from integrating the PDF over an interval.
4. Understand mean, median, and mode separately. They describe different aspects of the center of a distribution and can differ significantly when data are skewed.
5. Study variance and standard deviation together. Both describe dispersion, but standard deviation is expressed in the original data units.
6. Do not confuse standard deviation with standard error. Standard deviation measures data variability; standard error measures uncertainty in a sample statistic.
7. Correlation does not imply causation. Two variables can be correlated without one causing the other.
8. Learn conditional probability before Bayes' rule. Bayes' rule is much easier to understand once conditional probability is clear.
9. Practice with Python. NumPy, SciPy, and Matplotlib make it easier to explore distributions and statistical properties.

### 4. Classical Probability: The Combinatorial Approach

Until the developments of modern probability theory, much of probability focused on combinatorics.

Combinatorics is the mathematical study of counting and arranging possible outcomes.

For example, consider rolling a fair six-sided die.

There are six possible outcomes:

\\[ S=\\{1,2,3,4,5,6\\} \\]

The probability of rolling a 4 is:

\\[ P(X=4)=\frac{1}{6} \\]

The classical approach generally works with discrete outcomes that can be counted.

#### 4.1 Example Using Python

-------------------code----------------------
# Possible outcomes when rolling a fair die
outcomes = [1, 2, 3, 4, 5, 6]

# Count the outcomes
total_outcomes = len(outcomes)

# Count favorable outcomes
favorable_outcomes = outcomes.count(4)

# Calculate probability
probability = favorable_outcomes / total_outcomes

print("Probability of rolling a 4:", probability)
-------------------code----------------------

-------------------code----------------------
Probability of rolling a 4: 0.16666666666666666
-------------------code----------------------

Key idea: Classical probability is particularly useful when the possible outcomes are finite, countable, and equally likely.

### 5. Modern Probability Theory: The 20th Century

Modern probability theory expanded significantly during the 20th century.

The lecture mentions two important contributors:

- Andrey Kolmogorov.
- Richard von Mises.

Their work contributed to the development of modern mathematical foundations for probability.

#### 5.1 What Changed?

Classical probability mainly focused on discrete, countable outcomes.

Modern probability theory provides a much broader framework that can handle both:

| Type       | Description                             | Example               |
| ---------- | --------------------------------------- | --------------------- |
| Discrete   | Values that can be counted              | Number of customers   |
| Continuous | Values measured over a continuous range | Temperature or height |

This allows probability theory to work with real-valued measurements, including floating-point values in computing.

#### 6.2 Bayesian Statistics

- Model uncertain outcomes.
- Estimate the likelihood of events.

# Machine Learning Foundations: Probability and Information Theory

## Lecture Notes: Introduction to Probability Theory

### 1. What Is Probability Theory?

Probability theory is the mathematical study of processes and events that involve uncertainty.

It helps us describe how likely an event is to happen.

A probability is always a value between 0 and 1:

\\[ 0 \leq P(A) \leq 1 \\]

Where:

- \\(P(A)=0\\): The event is impossible.
- \\(P(A)=1\\): The event is certain.
- \\(0\<P(A)<1\\): The event has some possibility of occurring.

For example:

| Probability | Meaning    |
| ----------- | ---------- |
| 0.0         | Impossible |
| 0.25        | 25% chance |
| 0.5         | 50% chance |
| 0.75        | 75% chance |
| 1.0         | Certain    |

Key idea: Probability gives us a mathematical way to represent uncertainty instead of treating future events as completely predictable.

### 2. Using Historical Data to Predict Future Events

Probability theory allows us to build models of uncertain events using previously collected data.

The general process is:

1. Collect historical data.
2. Identify patterns or frequencies in the data.
3. Build a probability model.
4. Use the model to estimate the likelihood of future events.
5. Apply those estimates to events we have not observed yet.

#### 2.1 Example: Predicting Whether It Will Rain

Imagine we collected weather data for 100 days:

- 30 days had rain.
- 70 days had no rain.

The historical frequency of rainy days is:

\\[ P(\text{Rain})=\frac{30}{100}=0.3 \\]

This suggests a 30% historical frequency of rain.

#### Python Example

-------------------code----------------------
# Historical weather observations
rainy_days = 30
total_days = 100

# Calculate the historical probability
rain_probability = rainy_days / total_days

print("Probability of rain:", rain_probability)
print("Percentage:", rain_probability * 100, "%")
-------------------code----------------------

Output:

-------------------code----------------------
Probability of rain: 0.3
Percentage: 30.0 %
-------------------code----------------------

Important: This is a historical frequency, not necessarily an accurate forecast. A real weather model would consider additional information such as temperature, humidity, pressure, and location.

### 3. Relationship Between Probability and Statistics

Probability and statistics are closely related, but they serve different purposes.

- Probability: Uses mathematical models to reason about uncertain events.
- Statistics: Uses observed data to make inferences and evaluate confidence in those inferences.

Statistics helps us answer questions such as:

- Is an observed result likely to have occurred by chance?
- Is there meaningful evidence supporting a conclusion?
- Should we accept or reject a hypothesis?

#### 3.1 Example: Product A vs. Product B

Imagine a company wants to determine which email template performs better.

- Template A is sent to one group of customers.
- Template B is sent to another group.
- The company records how many people click each email.

Statistics can help determine whether the observed difference in click rates is meaningful or could reasonably be explained by random variation.

rate_b = template_b_clicks / template_b_sent

print("Template A click rate:", rate_a * 100, "%")
print("Template B click rate:", rate_b * 100, "%")

print("Difference:", (rate_b - rate_a) * 100, "percentage points")
-------------------code----------------------

Template B click rate: 15.0 %
Difference: 3.0 percentage points
-------------------code----------------------

Template B has a higher observed click rate.

However, this alone does not prove that Template B is genuinely better. Statistical testing can help evaluate whether the difference is likely to be meaningful.

### 4. Statistics and Hypothesis Testing

Statistics provides a framework for supporting or rejecting hypotheses using collected data.

A hypothesis is a statement or assumption that we want to investigate.

Examples:

- A new medicine improves recovery rates.
- A particular chemical reaction produces more of a desired substance.
- A website redesign increases customer purchases.
- Email Template B produces a higher click-through rate than Template A.

#### 4.1 Basic Hypothesis Testing Process

1. Formulate a hypothesis.
2. Collect relevant data.
3. Analyze the observations.
4. Evaluate whether the results provide sufficient evidence.
5. Decide whether to reject the original hypothesis.

Two common terms are:

- Null hypothesis (\\(H_0\\)): Usually represents no effect or no difference.
- Alternative hypothesis (\\(H_1\\)): Represents an effect or difference.

For the email example:

\\[ H_0: p_A=p_B \\]

\\[ H_1: p_A\neq p_B \\]

Where \\(p_A\\) and \\(p_B\\) are the true click-through rates.

Important: Hypothesis testing does not prove a hypothesis with absolute certainty. It evaluates how compatible the observed data is with a specified statistical model.

Like statistics, machine learning learns from observations and uses the learned patterns to make predictions.

However, machine learning is particularly useful when working with:

### 7. Key Concepts in Probability Theory

The lecture introduces four important concepts that will be explored in later lessons.

#### 7.1 Law of Large Numbers

The Law of Large Numbers states that as the number of independent observations increases, the sample average tends to get closer to the expected value.

For example, when flipping a fair coin repeatedly, the proportion of heads tends to approach 0.5 as the number of flips becomes large.

Python Example:

-------------------code----------------------
import numpy as np

# Simulate 10,000 coin flips
flips = np.random.choice(
    [0, 1],
    size=10000
)

# 1 represents heads
# 0 represents tails

# Calculate the proportion of heads
proportion_heads = np.mean(flips)

print("Proportion of heads:", proportion_heads)
-------------------code----------------------

The result should generally be close to 0.5, although it will vary between executions.

#### 7.2 Random Variables

A random variable is a variable whose value depends on the outcome of a random process.

For example, when rolling a die:

\\[ X \in \\{1,2,3,4,5,6\\} \\]

Here, \\(X\\) represents the result of the die roll.

Python Example:

-------------------code----------------------

# Simulate one die roll

print("Random variable X:", X)
-------------------code----------------------

#### 7.3 Probability Distributions

A probability distribution describes how probabilities are assigned to the possible values of a random variable.

For example, a fair six-sided die has an equal probability of producing each outcome:

\\[ P(X=x)=\frac{1}{6} \\]

for \\(x \in \\{1,2,3,4,5,6\\}\\).

Python Example:

-------------------code----------------------
import numpy as np

# Six possible outcomes
outcomes = np.array([1, 2, 3, 4, 5, 6])

# Equal probability for every outcome
probabilities = np.ones(6) / 6

for outcome, probability in zip(outcomes, probabilities):
    print(f"P(X={outcome}) = {probability:.4f}")
-------------------code----------------------

#### 7.4 Central Limit Theorem

The Central Limit Theorem states that, under suitable conditions, the distribution of sample means approaches a normal distribution as the sample size increases.

This is true even when the original population distribution is not normal, provided the relevant assumptions are satisfied.

Python Example:

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Generate a non-normal population
population = np.random.exponential(
    scale=2,
    size=100000
)

# Take repeated samples and calculate their means
sample_means = []

for _ in range(1000):
    sample = np.random.choice(
        population,
        size=50
    )

    sample_means.append(np.mean(sample))

# Plot the distribution of sample means
plt.hist(sample_means, bins=30, edgecolor="black")

plt.title("Central Limit Theorem")
plt.xlabel("Sample Mean")
plt.ylabel("Frequency")

plt.show()
-------------------code----------------------

The distribution of sample means should look approximately normal, even though the original population follows an exponential distribution.

# Machine Learning Foundations: Probability and Information Theory

## Lecture Notes: Events and Sample Spaces

### 1. Introduction

This lecture introduces two fundamental concepts in probability theory:

1. Sample Space: The set of all possible outcomes of an experiment.
2. Event: A particular outcome or a set of outcomes that we are interested in.

These concepts allow us to calculate the probability of an event by comparing the number of favorable outcomes with the total number of possible outcomes.

### 2. Sample Space

A sample space is the set of every possible outcome of a random experiment.

It is commonly represented by the Greek letter Omega:

\\[ \Omega \\]

#### 2.1 Example: Flipping a Fair Coin

A fair coin has two possible outcomes:

- Heads (H)
- Tails (T)

Therefore, the sample space is:

\\[ \Omega = \\{H,T\\} \\]

There are two possible outcomes.

#### Python Example

-------------------code----------------------
# Define the sample space of a coin flip
sample_space = {"H", "T"}

print("Sample space:", sample_space)
print("Number of possible outcomes:", len(sample_space))
-------------------code----------------------

Output:

-------------------code----------------------
Sample space: {'H', 'T'}
Number of possible outcomes: 2
-------------------code----------------------

Important: A fair coin means that both outcomes have equal probabilities.

\\[ P(H)=P(T)=0.5 \\]

### 3. Events

An event is a particular outcome or a collection of outcomes from a sample space.

For example, when flipping a coin:

- Getting heads is an event.
- Getting tails is another event.
- Getting either heads or tails represents the entire sample space.

We can represent an event using set notation.

\\[ A=\\{H\\} \\]

Here, event \\(A\\) means getting heads.

#### Python Example

-------------------code----------------------
# Define the sample space
sample_space = {"H", "T"}

# Define an event
event_heads = {"H"}

print("Sample space:", sample_space)
print("Event:", event_heads)
-------------------code----------------------

An event must contain outcomes that belong to the sample space.

### 4. Calculating Probability

When all possible outcomes are equally likely, we can calculate the probability of an event using:

\\[ P(A)=\frac{|A|}{|\Omega|} \\]

Where:

- \\(P(A)\\): Probability of event A.
- \\(|A|\\): Number of favorable outcomes.
- \\(|\Omega|\\): Total number of possible outcomes.

In simple terms:

\\[ \text{Probability}= \frac{\text{Favorable outcomes}}{\text{Total possible outcomes}} \\]

The result is always between 0 and 1.

#### 4.1 Example: Probability of Heads

For a fair coin:

\\[ \Omega=\\{H,T\\} \\]

The event of getting heads is:

\\[ A=\\{H\\} \\]

There is one favorable outcome and two possible outcomes.

\\[ P(H)=\frac{1}{2}=0.5 \\]

As a percentage:

\\[ 0.5\times100=50\\% \\]

#### Python Example

-------------------code----------------------
sample_space = {"H", "T"}
event_heads = {"H"}

probability_heads = len(event_heads) / len(sample_space)

print("Probability of heads:", probability_heads)
print("Percentage:", probability_heads * 100, "%")
-------------------code----------------------

Output:

-------------------code----------------------
Probability of heads: 0.5
Percentage: 50.0 %
-------------------code----------------------

#### 4.2 Example: Probability of Tails

Similarly:

\\[ P(T)=\frac{1}{2}=0.5=50\\% \\]

-------------------code----------------------
event_tails = {"T"}

probability_tails = len(event_tails) / len(sample_space)

print("Probability of tails:", probability_tails)
-------------------code----------------------

Both events have the same probability because the coin is fair.

### 5. Example: Drawing a Card from a Standard Deck

A standard deck contains 52 playing cards.

Therefore, the sample space contains 52 possible outcomes:

\\[ |\Omega|=52 \\]

We can use the same probability formula to calculate the probability of drawing different types of cards.

#### 5.1 Probability of Drawing the Ace of Spades

There is only one Ace of Spades in a standard deck.

\\[ P(\text{Ace of Spades})=\frac{1}{52} \\]

\\[ P\approx0.01923=1.92\\% \\]

#### Python Example

-------------------code----------------------
total_cards = 52
ace_of_spades = 1

probability = ace_of_spades / total_cards

print("Probability:", probability)
print("Percentage:", probability * 100, "%")
-------------------code----------------------

#### 5.2 Probability of Drawing Any Ace

There are four aces in a standard deck.

\\[ P(\text{Ace})=\frac{4}{52} \\]

\\[ P\approx0.07692=7.69\\% \\]

-------------------code----------------------
total_cards = 52
number_of_aces = 4

probability_ace = number_of_aces / total_cards

print("Probability of drawing an ace:", probability_ace)
print("Percentage:", probability_ace * 100, "%")
-------------------code----------------------

#### 5.3 Probability of Drawing a Spade

There are 13 spades in a standard deck.

\\[ P(\text{Spade})=\frac{13}{52} \\]

\\[ P(\text{Spade})=0.25=25\\% \\]

-------------------code----------------------
total_cards = 52
number_of_spades = 13

probability_spade = number_of_spades / total_cards

print("Probability of drawing a spade:", probability_spade)
print("Percentage:", probability_spade * 100, "%")
-------------------code----------------------

### 6. Events with Multiple Conditions: Ace or Spade

We are not limited to calculating probabilities for only one type of card.

We can also calculate the probability of drawing a card that satisfies multiple conditions.

For example:

What is the probability of drawing either an ace or a spade?

There are:

- 4 aces.
- 13 spades.
- 1 card that belongs to both groups: the Ace of Spades.

If we simply add 4 and 13, we count the Ace of Spades twice.

Therefore, we subtract the overlap:

\\[ |A\cup S|=|A|+|S|-|A\cap S| \\]

Substituting the values:

\\[ |A\cup S|=4+13-1=16 \\]

Therefore:

\\[ P(A\cup S)=\frac{16}{52} \\]

\\[ P(A\cup S)\approx0.3077=30.77\\% \\]

#### Python Example

-------------------code----------------------
total_cards = 52

number_of_aces = 4
number_of_spades = 13
overlap = 1  # Ace of Spades

favorable_outcomes = (
    number_of_aces
    + number_of_spades
    - overlap
)

probability = favorable_outcomes / total_cards

print("Favorable outcomes:", favorable_outcomes)
print("Probability of ace or spade:", probability)
print("Percentage:", probability * 100, "%")
-------------------code----------------------

Important: The word `or` in probability usually represents the union of events. When events overlap, avoid counting the shared outcomes twice.

### 7. Certain and Impossible Events

Two important special cases are:

#### 7.1 Certain Event

A certain event is an event that always happens.

For example, drawing any card from a standard deck means that we will definitely draw a card.

There are 52 favorable outcomes out of 52 possible outcomes.

\\[ P(\Omega)=\frac{52}{52}=1 \\]

Therefore:

\\[ P(\Omega)=1=100\\% \\]

#### 7.2 Impossible Event

An impossible event is an event that cannot happen.

For example, drawing a turnip from a standard deck of playing cards.

There are zero favorable outcomes.

\\[ P(\text{Turnip})=\frac{0}{52}=0 \\]

Therefore:

\\[ P(\text{Turnip})=0=0\\% \\]

#### Python Example

-------------------code----------------------
total_cards = 52

# Certain event
certain_event = 52
probability_certain = certain_event / total_cards

# Impossible event
impossible_event = 0
probability_impossible = impossible_event / total_cards

print("Certain event:", probability_certain)
print("Impossible event:", probability_impossible)
-------------------code----------------------

### 9. Important Notes and Best Practices

1. Sample space represents all possible outcomes. Use \\(\Omega\\) to represent it mathematically.
2. An event is a subset of the sample space. It can contain one outcome or several outcomes.
3. Probability ranges from 0 to 1. Zero means impossible, and one means certain.
4. The basic counting formula requires equally likely outcomes. Do not apply it blindly when outcomes have different probabilities.
5. Avoid double-counting overlapping events. For an `A or B` event, subtract the overlap once.
6. Use set notation to represent outcomes clearly. Curly brackets `{}` indicate a set.
7. Distinguish an event from an outcome. An outcome is one possible result; an event can contain one or more outcomes.
