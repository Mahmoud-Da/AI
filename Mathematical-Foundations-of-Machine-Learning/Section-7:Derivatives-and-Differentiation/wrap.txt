The first concept is the **Delta Method**.

Purpose:

* Compare two nearby points on a curve.
* Measure how much the function changes.
* Use smaller and smaller distances.
* Eventually compute the exact slope.

This creates the intuition behind derivatives.

---

## 4.2 The Differentiation Equation

Next, you'll learn the formal derivative equation.

Conceptually, it computes:

* Change in output

divided by

* Change in input

as the change becomes infinitely small.

The derivative is defined by:

[
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}
]

This equation combines:

* Limits
* Rate of change
* Tangent slope

into one formula.

---

]

Understanding these symbols is important because different textbooks use different notation.

* Quotient Rule
* Chain Rule

These rules make differentiation much faster and are heavily used in machine learning.

*** 59. The Delta Method ***
# Calculus I – The Delta Method (Computing Derivatives from First Principles)

## 1. Overview

The **Delta Method** is a classical technique used to find the **slope of a curve at a specific point**.

The main idea is simple:

* Pick a point on the curve.
* Pick another nearby point.
* Calculate the slope of the line between them (called a secant line).
* Move the second point closer and closer.
* As the distance approaches zero, the secant line becomes the **tangent line**.
* The tangent line's slope is the **derivative**.

This idea is the foundation of differential calculus.

---

# 13. Understanding Delta (Δ)

The Greek letter Delta (Δ) means **change**.

Examples:

Change in x

[
\Delta x=x_2-x_1
]

Change in y

[
\Delta y=y_2-y_1
]

Slope

[
m=\frac{\Delta y}{\Delta x}
]

---

# 14. Why Limits Are Needed

If Q is far away,

the slope only approximates the curve.

As

[
\Delta x\rightarrow0
]

Point Q moves infinitely close to P.

The secant line becomes the tangent line.

That tangent slope is the derivative.

This idea leads directly to the formal derivative definition introduced in the next lecture.

---

      ↓

      ↓

      ↓

      ↓

# 16. Full Final Code

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Function
def f(x):
    return x**2 + 2*x + 2

# Generate curve
x = np.linspace(-10, 10, 1000)
y = f(x)

# Point P
x1 = 2
y1 = f(x1)

# Small Delta x
delta_x = 1e-6

# Point Q
x2 = x1 + delta_x
y2 = f(x2)

# Slope
m = (y2 - y1) / (x2 - x1)

# Intercept
b = y1 - m*x1

# Tangent line
line = m*x + b

# Plot
plt.plot(x, y, label="Curve")
plt.scatter(x1, y1, label="P")
plt.scatter(x2, y2, label="Q")
plt.plot(x, line, label="Tangent")

plt.legend()
plt.show()

print("Slope =", m)
-------------------code----------------------

---

# 17. Important Notes

* Δ (Delta) means **change**.
* The slope between two points is called the **secant slope**.
* The slope at one exact point is called the **tangent slope**.
* The derivative is the tangent slope.
* The smaller Δx becomes, the more accurate the slope estimate becomes.
* Limits allow Δx to become infinitely small without actually being zero.

---

# 18. Best Practices

* Always understand the geometry before memorizing formulas.
* Remember that derivatives are simply **instantaneous slopes**.
* Practice computing slopes manually before using differentiation rules.
* Visualize how moving point Q closer to P improves the approximation.
* Keep in mind that every differentiation rule learned later is derived from this simple Delta Method.

# 19. Summary

The Delta Method provides an intuitive way to understand derivatives.

The process is:

1. Select a point on the curve.

2. Select a nearby second point.

3. Compute the slope using:

   [
   m=\frac{\Delta y}{\Delta x}
   ]

4. Move the second point closer.

5. Let

   [
   \Delta x\rightarrow0
   ]

6. The secant line becomes the tangent line.

7. The tangent slope is the **derivative**.

This concept is the mathematical foundation for all differentiation techniques and is essential for optimization methods used throughout machine learning, including gradient descent and neural network training.

# 13. Deriving the Derivative Formula

The slope equation is

[
m=\frac{\Delta y}{\Delta x}
]

As

[
\Delta x\rightarrow0
]

the slope becomes the derivative.

This gives

[
\frac{dy}{dx}
=============

\lim_{\Delta x\to0}
\frac{\Delta y}{\Delta x}
]

Since

[
\Delta y=y_2-y_1
]

the equation becomes

[
\frac{dy}{dx}
=============

\lim_{\Delta x\to0}
\frac{y_2-y_1}{\Delta x}
]

Replace

[
y_1=f(x)
]

and

[
y_2=f(x+\Delta x)
]

The final formula is:

This is the **definition of the derivative from first principles**.

---

* The line connecting these points is called the **secant line**.

# Why is the Derivative of x Equal to 1 and Not 0?

---

## The Core Idea

| Function | Type | Derivative | Reason |
| :--- | :--- | :--- | :--- |
| f(x) = 5 | **Constant** (does not change with x) | 0 | No change |
| f(x) = x | **Variable** (changes with x) | 1 | Change = 1 for each step |

---

## Part 1: The Difference Between a Constant and a Variable

### A Constant: Never Changes

-------------------code----------------------
f(x) = 5

No matter what x is:
f(0) = 5
f(10) = 5
f(100) = 5
f(1000) = 5

The value is always 5 -> No change -> Derivative = 0
-------------------code----------------------

---

### A Variable: Changes with x

-------------------code----------------------
f(x) = x

Try different values:
f(0) = 0
f(1) = 1
f(2) = 2
f(3) = 3
f(4) = 4

Every time x increases by 1, f(x) increases by 1
-> Constant change = 1 -> Derivative = 1
-------------------code----------------------

---

## Part 2: Visual Explanation (The Graph)

### Graph of f(x) = 5 (Constant):

-------------------code----------------------

^
|
5  --------------------  <- Horizontal line (slope = 0)
|
|
|

-------------------code----------------------

The line is horizontal -> slope = 0 -> derivative = 0

---

### Graph of f(x) = x (Variable):

-------------------code----------------------

^
|  * (4,4)
| * (3,3)
|* (2,2)
| * (1,1)
|  * (0,0)
0 ---------------------> x
-------------------code----------------------

The line is sloped at 45 degrees -> slope = 1 -> derivative = 1

---

## Part 3: Calculating the Slope (Why 1?)

### Slope = Change in y / Change in x

For f(x) = x:

| x1 | x2 | f(x1) | f(x2) | Δx | Δy | Slope |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 0 | 1 | 0 | 1 | 1 | 1 | 1 / 1 = 1 |
| 1 | 2 | 1 | 2 | 1 | 1 | 1 / 1 = 1 |
| 2 | 3 | 2 | 3 | 1 | 1 | 1 / 1 = 1 |
| 3 | 4 | 3 | 4 | 1 | 1 | 1 / 1 = 1 |

Every time x increases by 1, f(x) increases by 1
Slope = 1

---

## Part 4: Applying the Power Rule

Remember the Power Rule:
-------------------code----------------------
d/dx (x^n) = n * x^(n-1)
-------------------code----------------------

For f(x) = x:
-------------------code----------------------
x = x^1

The exponent n = 1

Apply the rule:
d/dx (x^1) = 1 * x^0 = 1 * 1 = 1
-------------------code----------------------

Answer: 1

---

## Part 5: Why Do People Make This Mistake?

### Reason: Confusing "Constant" with "Variable"

| Wrong | Correct |
| :--- | :--- |
| f(x) = 5 -> derivative = 0 | Correct (constant) |
| f(x) = x -> derivative = 0 | Wrong (variable) |
| f(x) = x -> derivative = 1 | Correct |

The golden rule:
- If the function is just a number (no x) -> derivative = 0
- If the function contains x -> derivative is NOT 0 (unless the exponent is 0)

---

| Situation | Function | Derivative = Speed |
| :--- | :--- | :--- |
| Car is parked (not moving) | f(x) = 5 (constant) | 0 |
| Car is moving at 1 km/hour | f(x) = x (variable) | 1 |

Constant = stopped (speed 0)
Variable = moving (speed not 0)

*** 64. The Constant Multiple Rule ***

# Calculus One – Differentiation Rules (Part 2)

# Constant Multiple Rule

---

# 1. Introduction

The **Constant Multiple Rule** is one of the most commonly used differentiation rules.

It states that if a function is multiplied by a constant, you can:

1. Ignore the constant temporarily.
2. Differentiate the variable part.
3. Multiply the result by the constant.

This rule is often used together with the **Power Rule**.

---

# 2. Constant Multiple Rule

## Rule

If:

[
y = C \cdot f(x)
]

then

Where:

* **C** = constant
* **f(x)** = any differentiable function

---

# 3. Why Does This Work?

A constant does **not** change with respect to (x).

Instead of differentiating everything together:

* Move the constant outside.
* Differentiate the variable expression.
* Multiply the result by the constant.

This makes differentiation much easier.

---

# 4. Step-by-Step Example

Suppose

[
y=x^4
]

Using the **Power Rule**

[
\frac{dy}{dx}=4x^3
]

Now suppose we want

[
\frac{d}{dx}(2y)
]

### Step 1

Move the constant outside.

[
2\frac{dy}{dx}
]

---

### Step 2

Replace the derivative of (y).

Since

[
\frac{dy}{dx}=4x^3
]

we get

[
2(4x^3)
]

---

### Step 3

Multiply.

[
8x^3
]

Final Answer

[
\frac{d}{dx}(2x^4)=8x^3
]

---

# 5. Easier Way to Think About It

Instead of separating (2y), simply write

[
y=2x^4
]

Then:

### Ignore the constant

Differentiate only

[
x^4
]

Using the Power Rule

[
4x^3
]

Finally multiply by the constant

[
2(4x^3)=8x^3
]

This is exactly the same result with fewer steps.

---

# 6. Step-by-Step Procedure

Whenever you see

[
C \cdot f(x)
]

follow these steps:

### Step 1

Leave the constant alone.

---

### Step 2

Differentiate only the variable expression.

---

### Step 3

Multiply the derivative by the constant.

Done.

---

*** 65. The Sum Rule ***

# Calculus One – Differentiation Rules (Part 3)

# Sum Rule

---

# 1. Introduction

The **Sum Rule** is another fundamental differentiation rule.

It states that when a function is made up of multiple terms separated by **+** or **−**, you can differentiate **each term independently** and then combine the results.

This makes differentiating large polynomial expressions much simpler.

---

# 2. Sum Rule

## Rule

If

[
y=f(x)+g(x)
]

then

Similarly,

[
\frac{d}{dx}(f(x)-g(x))
=======================

## \frac{d}{dx}f(x)

\frac{d}{dx}g(x)
]

---

# 3. Why Does This Work?

When terms are separated by **+** or **−**, each term contributes independently to the overall rate of change.

Therefore:

1. Differentiate the first term.
2. Differentiate the second term.
3. Add (or subtract) the results.

There is no need to differentiate the entire expression at once.

---

# 4. Step-by-Step Example

Suppose

[
y=x^4
]

and

[
w=x^9
]

We want to differentiate

[
y+w
]

---

### Step 1

Separate the terms.

[
\frac{d}{dx}(y+w)
=================

\frac{dy}{dx}
+
\frac{dw}{dx}
]

---

### Step 2

Differentiate the first term.

Using the Power Rule

[
\frac{d}{dx}(x^4)=4x^3
]

---

### Step 3

Differentiate the second term.

Using the Power Rule

[
\frac{d}{dx}(x^9)=9x^8
]

---

### Step 4

Combine the results.

Final Answer

[
\frac{d}{dx}(x^4+x^9)
=====================

4x^3+9x^8
]

---

]

*** 67. The Product Rule ***

# Calculus I – Product Rule (Structured Notes)

# 1. Lecture Overview

This lecture introduces the **Product Rule**, an important differentiation rule used when a function is the **product (multiplication)** of two functions.

Instead of expanding the multiplication first (which may be difficult or impossible), the Product Rule allows us to differentiate each function separately and combine the results.

---

# 2. What is the Product Rule?

Suppose two functions are:

* (W(x))
* (Z(x))

and

[
Y = W \cdot Z
]

The derivative is:

[
\boxed{
\frac{d}{dx}(WZ)
================

W\frac{dZ}{dx}
+
Z\frac{dW}{dx}
}
]

Notice the pattern:

* Keep the **first function** unchanged and differentiate the **second**.
* Then keep the **second function** unchanged and differentiate the **first**.
* Add the two results together.

A common memory trick is:

> First × derivative of Second + Second × derivative of First

---

# 3. When Should You Use the Product Rule?

Use the Product Rule whenever:

* Two (or more) functions are multiplied together.
* Expanding the multiplication first is difficult or impossible.
* The expression contains multiple differentiation rules that are easier to apply separately.

Examples:

* (x^2\sin x)
* (e^x(x+3))
* ((x^2+1)(x^3-5))

---

# 4. Example from the Lecture

[
Y=(6x^3)(7x^4)
]

Split the product into two functions:

[
W=6x^3
]

[

]

---

## Differentiate (W)

Using:

* Constant Multiple Rule
* Power Rule

[
W=6x^3
]

Derivative:

[
\frac{dW}{dx}
=============

18x^2
]

---

]

]

Examples

[

]

[

]

Only **exponents are added**.

Do **not** multiply exponents.

# 11. Important Notes

* Use the Product Rule **only when functions are multiplied**.
* Do **not** use the Sum Rule for multiplication.
* Differentiate each function separately before substituting into the Product Rule.
* Keep one function unchanged while differentiating the other.
* Remember the order:

[
WZ' + ZW'
]

* When multiplying powers of the same variable:

[
x^a x^b = x^{a+b}
]

* After applying the Product Rule, always simplify like terms.

---

# 12. Best Practices

* Clearly identify the two functions before differentiating.
* Compute each derivative separately to avoid mistakes.
* Substitute into the Product Rule only after both derivatives are known.
* Simplify coefficients and combine like terms at the end.
* Expanding the multiplication first may work in simple cases, but the Product Rule is more general and is essential for more complex expressions.

]

This rule becomes especially valuable when working with more complicated functions in calculus and machine learning, where expanding expressions beforehand is often impractical or impossible.

# What Does dY/dx Mean?

Great question! Many people confuse the derivative with the point where axes meet. Let me explain the difference in the simplest way possible.

---

## The Short Answer

**No, dY/dx does NOT mean "the point where y and x meet"!**

**dY/dx means:**
> "The rate of change of y with respect to x"
> Or in other words: "How much does y change when x changes by a tiny amount"

---

## Part 1: The Difference Between a "Point" and a "Rate of Change"

### A Point = A Specific Location

-------------------code----------------------
The point (2, 5) means:
x = 2
y = 5
-------------------code----------------------

This is a specific location on the graph.

---

### The Derivative = Rate of Change

-------------------code----------------------
dY/dx at x = 2 means:
"When x = 2, how much does y change for each change in x?"
-------------------code----------------------

This is the speed of change at that location, not the location itself.

---

## Part 2: Car Analogy

| Question | Answer |
| :--- | :--- |
| Where are you now? | Location = The point (x, y) |
| How fast are you going? | Speed = The derivative dY/dx |

**The difference:**
- Location tells you **where** you are
- Speed tells you **how fast** you are moving

This is exactly the same difference between a point and a derivative!

---

## Part 3: Visual Explanation

### The Graph:

-------------------code----------------------
y
^
|        *
|       *  <- The point (2, 5)
|      *
|     *
|    *
|   *
|  *
| *
|*
+----------------> x
-------------------code----------------------

**The point (2, 5):** A specific location on the curve

**The derivative dY/dx at x = 2:** The slope of the curve at that point (how steep it is)

---

## Part 4: Example with Numbers

### Function: y = x²

| x | y = x² | dY/dx = 2x |
| :--- | :--- | :--- |
| 1 | 1 | 2 |
| 2 | 4 | 4 |
| 3 | 9 | 6 |
| 4 | 16 | 8 |

**At each point:**
- **y** = the location of the point on the vertical axis
- **dY/dx** = the speed of change at that point

**Example: at x = 2**
- The point is (2, 4)
- The derivative is 4 (meaning y changes by 4 for each change in x)

---

## Part 5: Meaning of the Symbols

### dY/dx has two parts:

| Symbol | Meaning |
| :--- | :--- |
| **dY** | A very small change in Y |
| **dx** | A very small change in X |
| **dY/dx** | The rate of change of Y with respect to X |

---

## Part 6: Why Do We Use "d"?

**d** means "a very small change" (Differential)

**Comparison:**
-------------------code----------------------
Δy/Δx = Rate of change between two far points (average speed)
dy/dx = Rate of change at a single point (instantaneous speed)
-------------------code----------------------

---

## Part 7: Final Summary

| Question | Answer |
| :--- | :--- |
| Does dY/dx mean where y and x meet? | **No**, this is a common misunderstanding |
| What does dY/dx mean? | The rate of change of Y with respect to X |
| What does it tell us? | Speed of change or slope of the curve |
| What is the difference between a point and a derivative? | Point = location, derivative = speed |
| Example of a point? | (2, 5) |
| Example of a derivative? | dY/dx = 4 at x = 2 |

---

## The Most Important Sentence

> **dY/dx does NOT mean "the point where axes meet". It means "the rate of change of Y with respect to X". It tells us the speed of change at any point, not the location of the point itself.**

---

## Part 8: Always Remember

-------------------code----------------------
Point (x, y) = Where are you? (location)
Derivative dy/dx = How fast are you moving? (rate of change)
-------------------code----------------------

**Both are important, but they are completely different things!**

# Calculus I – Quotient Rule (Structured Notes)

# 1. Lecture Overview

This lecture introduces the **Quotient Rule**, which is used to differentiate functions written as **fractions**.

The Quotient Rule is closely related to the Product Rule but is specifically designed for expressions where one function is divided by another.

The lecture explains:

* What the Quotient Rule is
* Why it is needed
* How to apply it step-by-step
* A complete worked example

---

# 2. What is the Quotient Rule?

Suppose a function is written as:

[
Y=\frac{W}{Z}
]

where:

* (W) = numerator
* (Z) = denominator

The derivative is:

[
\boxed{
\frac{d}{dx}\left(\frac{W}{Z}\right)
====================================

\frac{Z\frac{dW}{dx}-W\frac{dZ}{dx}}{Z^2}
}
]

This is called the **Quotient Rule** (or Fraction Rule).

---

# 3. Comparing Product Rule and Quotient Rule

## Product Rule

For multiplication:

[
\frac{d}{dx}(WZ)
================

WZ'+ZW'
]

Notice the **plus (+)** sign.

---

## Quotient Rule

For division:

[
\frac{d}{dx}\left(\frac{W}{Z}\right)
====================================

\frac{ZW'-WZ'}{Z^2}
]

Differences:

* Uses a **minus (-)** sign.
* Divides by the **square of the denominator**.

---

# 4. When Should You Use the Quotient Rule?

Use the Quotient Rule whenever:

* One function is divided by another.
* The expression is written as a fraction.
* Simplifying the fraction first is difficult or impossible.

Examples:

[
\frac{x^2}{x+1}
]

[
\frac{\sin x}{x}
]

[
\frac{e^x}{x^2+1}
]

---

# 5. Example from the Lecture

]

]

[

]

]

* Power Rule

Result:

[
\boxed{
W'=8x
}
]

*** 69. The Chain Rule ***
# Calculus I – The Chain Rule

## 1. Overview

The **Chain Rule** is one of the most important differentiation rules in calculus and machine learning.

It is used whenever a function is **inside another function** (nested or composite functions).

It is especially important because it is the mathematical foundation behind:

* Gradient Descent
* Backpropagation
* Neural Networks
* Deep Learning
* Automatic Differentiation

This rule is used throughout machine learning, from simple linear regression to modern deep learning models.

---

# 2. Why the Chain Rule Matters

Many machine learning models are built from multiple functions connected together.

Example:

-------------------code----------------------
Input
   ↓
Function 1
   ↓
Function 2
   ↓
Function 3
   ↓
Output
-------------------code----------------------

Instead of differentiating the whole expression at once, the Chain Rule lets us differentiate **one layer at a time**.

This is exactly how **backpropagation** works in neural networks.

---

# 3. Composite (Nested) Functions

Consider:

[
y=(5x+25)^3
]

This is difficult to differentiate directly.

Instead, separate it into two functions.

### Inner function

[
u=5x+25
]

### Outer function

[
y=u^3
]

Now the complicated expression becomes two simple functions.

---

# 4. The Chain Rule Formula

If

[
y=f(u)
]

and

[
u=g(x)
]

then

[
\boxed{\frac{dy}{dx}=\frac{dy}{du}\times\frac{du}{dx}}
]

The intermediate variable cancels:

[
\frac{dy}{du}\times\frac{du}{dx}
================================

\frac{dy}{dx}
]

This makes differentiation much easier.

---

# 5. Step-by-Step Example

Given

[
y=(2x^2+8)^2
]

---

## Step 1 — Define the Inner Function

Let

[
u=2x^2+8
]

Then

[
y=u^2
]

---

## Step 2 — Differentiate the Inner Function

Use:

* Sum Rule
* Constant Multiple Rule
* Power Rule

Constant disappears:

[
\frac{d}{dx}(8)=0
]

Differentiate

[
2x^2
]

Power Rule:

[
x^2 \rightarrow 2x
]

Multiply by 2:

[
\boxed{\frac{du}{dx}=4x}
]

---

## Step 3 — Differentiate the Outer Function

Differentiate

[
y=u^2
]

Power Rule:

[
\boxed{\frac{dy}{du}=2u}
]

Replace (u):

[
2(2x^2+8)
]

Simplify:

[
\boxed{\frac{dy}{du}=4x^2+16}
]

---

## Step 4 — Apply the Chain Rule

Multiply both derivatives.

[
\frac{dy}{dx}
=============

(4x)(4x^2+16)
]

Multiply:

[
4x\times4x^2=16x^3
]

[
4x\times16=64x
]

Final answer:

[
\boxed{\frac{dy}{dx}=16x^3+64x}
]

---

# 6. Complete Worked Example

### Original Function

[
y=(2x^2+8)^2
]

---

### Inner Function

[
u=2x^2+8
]

---

### Outer Function

[
y=u^2
]

---

### Differentiate Inner Function

[
\frac{du}{dx}=4x
]

---

### Differentiate Outer Function

[
\frac{dy}{du}=2u
]

Replace (u):

[
4x^2+16
]

---

### Chain Rule

[
\frac{dy}{dx}
=============

(4x)(4x^2+16)

# 8. How the Chain Rule Works Conceptually

Suppose we have

-------------------code----------------------
x
↓
u
↓
y
-------------------code----------------------

Instead of jumping directly from **x → y**, we calculate:

1. Change from **x to u**
2. Change from **u to y**
3. Multiply them together

This "chain" of derivatives gives the final derivative.

---

# 9. Relationship to Machine Learning

The lecture emphasizes that the Chain Rule is essential because it powers:

### Gradient Descent

* Computes gradients used to minimize loss functions.

### Backpropagation

* Computes gradients through many neural network layers.
* Makes training deep neural networks efficient.

### Deep Learning

A deep neural network is essentially a long chain of nested functions.

The Chain Rule allows gradients to flow through every layer.

# 10. Rules Used Together

To solve Chain Rule problems, you often combine earlier differentiation rules.

| Rule                   | Purpose                                |
| ---------------------- | -------------------------------------- |
| Constant Rule          | Derivative of constants is 0           |
| Power Rule             | Differentiate powers of variables      |
| Constant Multiple Rule | Keep constants outside differentiation |
| Sum Rule               | Differentiate each term separately     |
| Chain Rule             | Differentiate nested functions         |

---

# 11. Best Practices

* Always check whether a function is nested before differentiating.
* Define the inner function using a temporary variable (commonly (u)).
* Differentiate the inner and outer functions separately.
* Substitute the inner function back before multiplying.
* Multiply the derivatives only after both have been computed.
* Simplify the final expression.

* The **Chain Rule** is used for **nested (composite) functions**.
* Break a complex function into an **inner function** and an **outer function**.

=============

\frac{dy}{du}
\times
\frac{du}{dx}
]

* This rule is fundamental in machine learning because it enables **gradient descent**, **backpropagation**, and the training of **deep neural networks**.

]

differentiates to

# 7. The Key Pattern for Multiple Chain Rules

For a function with several nested layers:

-------------------code----------------------
x → t → u → y
-------------------code----------------------

differentiate each layer:

-------------------code----------------------
dy/du
du/dt
dt/dx
-------------------code----------------------

Then multiply:

[
\frac{dy}{dx}
=============

\frac{dy}{du}
\frac{du}{dt}
\frac{dt}{dx}
]

The intermediate terms cancel conceptually:

[
\frac{dy}{\cancel{du}}
\frac{\cancel{du}}{\cancel{dt}}
\frac{\cancel{dt}}{dx}
======================

\frac{dy}{dx}
]

This is why it is called the **Chain Rule**.

---

# 8. How to Decide Which Rule to Use

A useful review strategy is to look at the structure of the function first.

| Function structure       | Rule                           |
| ------------------------ | ------------------------------ |
| Constant                 | Constant Rule                  |
| (x^n)                    | Power Rule                     |
| (cx^n)                   | Constant Multiple + Power Rule |
| (f(x)+g(x))              | Sum Rule                       |
| (f(x)g(x))               | Product Rule                   |
| (\frac{f(x)}{g(x)})      | Quotient Rule                  |
| (f(g(x)))                | Chain Rule                     |
| Several nested functions | Chain Rule repeatedly          |

In complicated expressions, **multiple rules can be required simultaneously**.

For example:

[
(x^2+5x)^6
]

requires:

* Sum Rule
* Power Rule
* Constant Multiple Rule
* Chain Rule

---

# 9. Important Notes and Best Practices

### 1. Work from the inside out

For Chain Rule problems, identify the **innermost function first**.

For example:

[
y=\frac{1}{((x^4+1)^5+7)}
]

think:

-------------------code----------------------
x
↓
x⁴ + 1
↓
(x⁴ + 1)⁵ + 7
↓
1 / [(x⁴ + 1)⁵ + 7]
-------------------code----------------------

This makes the structure much easier to understand.

### 2. Do not expand unnecessarily

For example:

[
6(x^2+5x)^5(2x+5)
]

is usually better than expanding everything.

Likewise:

[
\frac{-20x^3(x^4+1)^4}
{((x^4+1)^5+7)^2}
]

is much easier to understand than a huge expanded polynomial.

### 3. Name intermediate functions

For complicated Chain Rule problems, use:

[
t,\ u,\ v,\ldots
]

This prevents you from losing track of which layer you are differentiating.

### 4. Check the structure before calculating

Do not immediately start applying rules.

First ask:

> Is this a product, quotient, nested function, or combination of several structures?

Then choose the appropriate rule.

*** 71. The Power Rule on a Function Chain ***
# 1. Power Rule on a Function Chain

The **power rule on a function chain** combines two rules we already learned:

1. **Power Rule**
2. **Chain Rule**

It gives us a faster way to differentiate expressions where a function is raised to a power.

---

# 2. The Rule

Suppose we have:

[
y = u^n
]

where (u) is itself a function of (x).

The rule is:

In simple terms:

1. Bring the exponent (n) in front.
2. Reduce the exponent by 1.
3. Multiply by the derivative of the inside function (du/dx).

This is essentially the **power rule + chain rule in one step**.

---

# 3. Example: (y=(3x+1)^2)

This is the same function used in the previous advanced exercises.

We have:

[
y=(3x+1)^2
]

The expression has a nested structure:

* Inner function: (3x+1)
* Outer operation: raising the inner function to the power of 2

## Step 1: Identify the inner function

Let:

[
u=3x+1
]

The exponent is:

[
n=2
]

---

## Step 2: Differentiate the inner function

Differentiate:

[
u=3x+1
]

Using the constant rule and constant multiple rule:

[
\frac{du}{dx}=3
]

In Python, we could represent the inner function as:

-------------------code----------------------
def u(x):
    return 3 * x + 1
-------------------code----------------------

And conceptually its derivative is:

-------------------code----------------------
du_dx = 3
-------------------code----------------------

---

# 4. Apply the Power Rule on a Function Chain

Using:

[
\frac{dy}{dx}=n u^{n-1}\frac{du}{dx}
]

Substitute:

* (n=2)
* (u=3x+1)
* (du/dx=3)

We get:

[
\frac{dy}{dx}
=============

2(3x+1)^{2-1}(3)
]

Since (2-1=1):

[
\frac{dy}{dx}
=============

2(3x+1)(3)
]

Multiply:

[
\frac{dy}{dx}=6(3x+1)
]

And finally:

[
\boxed{\frac{dy}{dx}=18x+6}
]

This is the same answer obtained previously using the full chain-rule procedure.

---

# 5. Why This Rule Is Useful

Previously, with the chain rule, we had to:

1. Identify the inner function.
2. Identify the outer function.
3. Differentiate the inner function.
4. Differentiate the outer function.
5. Chain the derivatives together.

The power rule on a function chain lets us perform this much more directly:

-------------------code----------------------
Identify the power
       ↓
Bring power in front
       ↓
Reduce power by 1
       ↓
Multiply by derivative of inside
-------------------code----------------------

So instead of separately calculating two derivatives and then multiplying them, we can use one compact rule.

---

# 6. Code Representation

The lecture is primarily mathematical, but we can represent the calculation in Python.

## Step 1: Define the original function

-------------------code----------------------
def f(x):
    return (3 * x + 1) ** 2
-------------------code----------------------

## Step 2: Define the derivative

Using the power rule on a function chain:

-------------------code----------------------
def df_dx(x):
    return 2 * (3 * x + 1) ** (2 - 1) * 3
-------------------code----------------------

## Step 3: Simplify the implementation

Since the exponent becomes 1:

-------------------code----------------------
def df_dx(x):
    return 2 * (3 * x + 1) * 3
-------------------code----------------------

Or:

-------------------code----------------------
def df_dx(x):
    return 18 * x + 6
-------------------code----------------------

All three derivative representations are mathematically equivalent.

---

# 7. Comparing With the Full Chain Rule

Previously we would have done:

-------------------code----------------------
y = u²
u = 3x + 1

dy/du = 2u
du/dx = 3

dy/dx = (dy/du)(du/dx)
-------------------code----------------------

Then substitute (u=3x+1):

-------------------code----------------------
dy/dx = 2(3x+1)(3)
-------------------code----------------------

The new power-rule-on-a-function-chain approach goes directly to:

-------------------code----------------------
dy/dx = 2(3x+1)¹(3)
-------------------code----------------------

So the result is identical, but the calculation is shorter.

# 11. Advanced Differentiation Rules

The segment then introduced three major rules.

## 11.1 Product Rule

For two functions (W) and (Z):

[
\frac{d(WZ)}{dx}
================

W\frac{dZ}{dx}
+
Z\frac{dW}{dx}
]

The important pattern is:

-------------------code----------------------
first × derivative of second
+
second × derivative of first
-------------------code----------------------

---

## 11.2 Quotient Rule

For:

[
y=\frac{W}{Z}
]

the quotient rule uses:

[
\frac{dy}{dx}
=============

\frac{
Z\frac{dW}{dx}
--------------

W\frac{dZ}{dx}
}{
Z^2
}
]

The important pattern is:

-------------------code----------------------
denominator × derivative of numerator
-
numerator × derivative of denominator
--------------------------------------
             denominator²
-------------------code----------------------

---

## 11.3 Chain Rule

The chain rule handles **nested/composite functions**.

For:

-------------------code----------------------
y = outer(inner(x))
-------------------code----------------------

we can differentiate:

-------------------code----------------------
dy/dx = dy/du × du/dx
-------------------code----------------------

The intermediate (du) effectively cancels:

-------------------code----------------------
dy   du
-- × --
du   dx

   ↓

dy
--
dx
-------------------code----------------------

This is particularly important in machine learning because neural networks can be viewed as long chains of nested functions.

# 13. Final Rule: Power Rule on a Function Chain

The final rule combines:

-------------------code----------------------
Power Rule
+
Chain Rule
-------------------code----------------------

The general form is:

[
\frac{dy}{dx}=n u^{n-1}\frac{du}{dx}
]

-------------------code----------------------
# Power Rule on a Function Chain
# Example:
# y = (3x + 1)^2

# Original function
def f(x):
    return (3 * x + 1) ** 2


# Inner function
def u(x):
    return 3 * x + 1


# Derivative of the inner function
def du_dx(x):
    return 3


# Derivative using the power rule on a function chain
def df_dx(x):
    n = 2
    return n * u(x) ** (n - 1) * du_dx(x)


# Simplified derivative:
# dy/dx = 18x + 6
def df_dx_simplified(x):
    return 18 * x + 6


# Example calculation
x = 2

print("f(x) =", f(x))
print("Derivative using chain-power rule =", df_dx(x))
print("Simplified derivative =", df_dx_simplified(x))
