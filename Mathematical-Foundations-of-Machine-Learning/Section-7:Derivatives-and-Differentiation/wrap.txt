The first concept is the **Delta Method**.

* Measure how much the function changes.
* Use smaller and smaller distances.
* Eventually compute the exact slope.

## 4.2 The Differentiation Equation

Next, you'll learn the formal derivative equation.

Conceptually, it computes:

* Change in output

divided by

* Change in input

as the change becomes infinitely small.

The derivative is defined by:

[
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}
]

This equation combines:

* Limits
* Rate of change
* Tangent slope

into one formula.

These rules make differentiation much faster and are heavily used in machine learning.

# Calculus I – The Delta Method (Computing Derivatives from First Principles)

## 1. Overview

The **Delta Method** is a classical technique used to find the **slope of a curve at a specific point**.

The main idea is simple:

* Pick a point on the curve.
* Pick another nearby point.
* Calculate the slope of the line between them (called a secant line).
* Move the second point closer and closer.
* As the distance approaches zero, the secant line becomes the **tangent line**.
* The tangent line's slope is the **derivative**.

This idea is the foundation of differential calculus.

---

# 13. Understanding Delta (Δ)

The Greek letter Delta (Δ) means **change**.

Examples:

Change in x

[
\Delta x=x_2-x_1
]

Change in y

[
\Delta y=y_2-y_1
]

Slope

[
m=\frac{\Delta y}{\Delta x}
]

---

# 14. Why Limits Are Needed

If Q is far away,

the slope only approximates the curve.

As

[
\Delta x\rightarrow0
]

Point Q moves infinitely close to P.

The secant line becomes the tangent line.

That tangent slope is the derivative.

This idea leads directly to the formal derivative definition introduced in the next lecture.

---

# 16. Full Final Code

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Function
def f(x):
    return x**2 + 2*x + 2

# Generate curve
x = np.linspace(-10, 10, 1000)
y = f(x)

# Point P
x1 = 2
y1 = f(x1)

# Small Delta x
delta_x = 1e-6

# Point Q
x2 = x1 + delta_x
y2 = f(x2)

# Slope
m = (y2 - y1) / (x2 - x1)

# Intercept
b = y1 - m*x1

# Tangent line
line = m*x + b

# Plot
plt.plot(x, y, label="Curve")
plt.scatter(x1, y1, label="P")
plt.scatter(x2, y2, label="Q")
plt.plot(x, line, label="Tangent")

plt.legend()
plt.show()

print("Slope =", m)
-------------------code----------------------

---

# 17. Important Notes

* Δ (Delta) means **change**.
* The slope between two points is called the **secant slope**.
* The slope at one exact point is called the **tangent slope**.
* The derivative is the tangent slope.
* The smaller Δx becomes, the more accurate the slope estimate becomes.
* Limits allow Δx to become infinitely small without actually being zero.

---

# 18. Best Practices

* Always understand the geometry before memorizing formulas.
* Remember that derivatives are simply **instantaneous slopes**.
* Practice computing slopes manually before using differentiation rules.
* Visualize how moving point Q closer to P improves the approximation.
* Keep in mind that every differentiation rule learned later is derived from this simple Delta Method.

# 19. Summary

The Delta Method provides an intuitive way to understand derivatives.

The process is:

1. Select a point on the curve.

2. Select a nearby second point.

3. Compute the slope using:

   [
   m=\frac{\Delta y}{\Delta x}
   ]

4. Move the second point closer.

5. Let

   [
   \Delta x\rightarrow0
   ]

6. The secant line becomes the tangent line.

7. The tangent slope is the **derivative**.

This concept is the mathematical foundation for all differentiation techniques and is essential for optimization methods used throughout machine learning, including gradient descent and neural network training.

# 13. Deriving the Derivative Formula

The slope equation is

[
m=\frac{\Delta y}{\Delta x}
]

As

[
\Delta x\rightarrow0
]

the slope becomes the derivative.

This gives

[
\frac{dy}{dx}
=============

\lim_{\Delta x\to0}
\frac{\Delta y}{\Delta x}
]

Since

[
\Delta y=y_2-y_1
]

the equation becomes

[
\frac{dy}{dx}
=============

\lim_{\Delta x\to0}
\frac{y_2-y_1}{\Delta x}
]

Replace

[
y_1=f(x)
]

and

[
y_2=f(x+\Delta x)
]

The final formula is:

This is the **definition of the derivative from first principles**.

---

# Why is the Derivative of x Equal to 1 and Not 0?

---

## The Core Idea

| Function | Type | Derivative | Reason |
| :--- | :--- | :--- | :--- |
| f(x) = 5 | **Constant** (does not change with x) | 0 | No change |
| f(x) = x | **Variable** (changes with x) | 1 | Change = 1 for each step |

---

## Part 1: The Difference Between a Constant and a Variable

### A Constant: Never Changes

-------------------code----------------------
f(x) = 5

No matter what x is:
f(0) = 5
f(10) = 5
f(100) = 5
f(1000) = 5

The value is always 5 -> No change -> Derivative = 0
-------------------code----------------------

---

### A Variable: Changes with x

-------------------code----------------------
f(x) = x

Try different values:
f(0) = 0
f(1) = 1
f(2) = 2
f(3) = 3
f(4) = 4

Every time x increases by 1, f(x) increases by 1
-> Constant change = 1 -> Derivative = 1
-------------------code----------------------

---

## Part 2: Visual Explanation (The Graph)

### Graph of f(x) = 5 (Constant):

-------------------code----------------------
y
^
|
5  --------------------  <- Horizontal line (slope = 0)
|
|
|
0  ---------------------> x
-------------------code----------------------

The line is horizontal -> slope = 0 -> derivative = 0

---

### Graph of f(x) = x (Variable):

-------------------code----------------------
y
^
|  * (4,4)
| * (3,3)
|* (2,2)
| * (1,1)
|  * (0,0)
0 ---------------------> x
-------------------code----------------------

The line is sloped at 45 degrees -> slope = 1 -> derivative = 1

---

## Part 3: Calculating the Slope (Why 1?)

### Slope = Change in y / Change in x

For f(x) = x:

| x1 | x2 | f(x1) | f(x2) | Δx | Δy | Slope |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 0 | 1 | 0 | 1 | 1 | 1 | 1 / 1 = 1 |
| 1 | 2 | 1 | 2 | 1 | 1 | 1 / 1 = 1 |
| 2 | 3 | 2 | 3 | 1 | 1 | 1 / 1 = 1 |
| 3 | 4 | 3 | 4 | 1 | 1 | 1 / 1 = 1 |

Every time x increases by 1, f(x) increases by 1
Slope = 1

---

## Part 4: Applying the Power Rule

Remember the Power Rule:
-------------------code----------------------
d/dx (x^n) = n * x^(n-1)
-------------------code----------------------

For f(x) = x:
-------------------code----------------------
x = x^1

The exponent n = 1

Apply the rule:
d/dx (x^1) = 1 * x^0 = 1 * 1 = 1
-------------------code----------------------

Answer: 1

---

## Part 5: Why Do People Make This Mistake?

### Reason: Confusing "Constant" with "Variable"

| Wrong | Correct |
| :--- | :--- |
| f(x) = 5 -> derivative = 0 | Correct (constant) |
| f(x) = x -> derivative = 0 | Wrong (variable) |
| f(x) = x -> derivative = 1 | Correct |

The golden rule:
- If the function is just a number (no x) -> derivative = 0
- If the function contains x -> derivative is NOT 0 (unless the exponent is 0)

---

## Part 6: Simple Analogy

### Analogy: Car Speed

| Situation | Function | Derivative = Speed |
| :--- | :--- | :--- |
| Car is parked (not moving) | f(x) = 5 (constant) | 0 |
| Car is moving at 1 km/hour | f(x) = x (variable) | 1 |

Constant = stopped (speed 0)
Variable = moving (speed not 0)

## Part 8: How to Remember Easily

Simple rule to memorize:

> If the function contains x -> use the Power Rule

## Part 9: Final Summary

| Question | Answer |
| :--- | :--- |
| Why is derivative of 5 = 0? | Because it is constant and never changes |
| Why is derivative of x = 1? | Because it changes at a rate of 1 per unit of x |
| What is the Power Rule? | d/dx (x^n) = n * x^(n-1) |

> The derivative of x is 1 because x changes at a rate of 1 for every change in x. The derivative of 5 is 0 because 5 never changes. The difference is: a constant does not change, but a variable does change.

# Calculus One – Differentiation Rules (Part 2)

# Constant Multiple Rule

---

# 1. Introduction

The **Constant Multiple Rule** is one of the most commonly used differentiation rules.

It states that if a function is multiplied by a constant, you can:

1. Ignore the constant temporarily.
2. Differentiate the variable part.
3. Multiply the result by the constant.

This rule is often used together with the **Power Rule**.

---

# 2. Constant Multiple Rule

## Rule

If:

[
y = C \cdot f(x)
]

then

Where:

* **C** = constant
* **f(x)** = any differentiable function

---

# 3. Why Does This Work?

A constant does **not** change with respect to (x).

Instead of differentiating everything together:

* Move the constant outside.
* Differentiate the variable expression.
* Multiply the result by the constant.

This makes differentiation much easier.

---

# 4. Step-by-Step Example

Suppose

[
y=x^4
]

Using the **Power Rule**

[
\frac{dy}{dx}=4x^3
]

Now suppose we want

[
\frac{d}{dx}(2y)
]

### Step 1

Move the constant outside.

[
2\frac{dy}{dx}
]

---

### Step 2

Replace the derivative of (y).

Since

[
\frac{dy}{dx}=4x^3
]

we get

[
2(4x^3)
]

---

### Step 3

Multiply.

[
8x^3
]

Final Answer

[
\frac{d}{dx}(2x^4)=8x^3
]

---

# 5. Easier Way to Think About It

Instead of separating (2y), simply write

[
y=2x^4
]

Then:

### Ignore the constant

Differentiate only

[
x^4
]

Using the Power Rule

[
4x^3
]

Finally multiply by the constant

[
2(4x^3)=8x^3
]

This is exactly the same result with fewer steps.

---

# 6. Step-by-Step Procedure

Whenever you see

[
C \cdot f(x)
]

follow these steps:

### Step 1

Leave the constant alone.

---

### Step 2

Differentiate only the variable expression.

---

### Step 3

Multiply the derivative by the constant.

Done.

# 14. Full Final Code

-------------------code----------------------
def derivative_constant_multiple(coefficient, exponent):
    """
    Differentiate coefficient * x^exponent
    using the Constant Multiple Rule
    and the Power Rule.
    """
    new_coefficient = coefficient * exponent
    new_exponent = exponent - 1
    return new_coefficient, new_exponent


examples = [
    (2, 4),
    (3, 5),
    (7, 2),
    (10, 1),
    (5, 3)
]

for coefficient, exponent in examples:
    coef, power = derivative_constant_multiple(coefficient, exponent)

    if power == 0:
        print(f"d/dx({coefficient}x^{exponent}) = {coef}")
    elif power == 1:
        print(f"d/dx({coefficient}x^{exponent}) = {coef}x")
    else:
        print(f"d/dx({coefficient}x^{exponent}) = {coef}x^{power}")
-------------------code----------------------

# 15. Summary

* The **Constant Multiple Rule** allows you to move a constant outside the differentiation operation.
* Differentiate **only the variable part** of the expression.
* After finding the derivative, multiply the result by the constant.
* This rule is almost always used together with the **Power Rule** when differentiating polynomial functions.
* Example:

[
\frac{d}{dx}(2x^4)
=2\cdot\frac{d}{dx}(x^4)
=2(4x^3)
=8x^3
]

This simple pattern will be used repeatedly in calculus and later in machine learning when differentiating cost functions and optimization equations.
