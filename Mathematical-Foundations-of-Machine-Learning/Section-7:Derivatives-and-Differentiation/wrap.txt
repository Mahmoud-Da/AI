## 4.1 The Delta Method

The first concept is the **Delta Method**.

Purpose:

* Compare two nearby points on a curve.
* Measure how much the function changes.
* Use smaller and smaller distances.
* Eventually compute the exact slope.

This creates the intuition behind derivatives.

---

## 4.2 The Differentiation Equation

Next, you'll learn the formal derivative equation.

Conceptually, it computes:

* Change in output

divided by

* Change in input

as the change becomes infinitely small.

The derivative is defined by:

[
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}
]

This equation combines:

* Limits
* Rate of change
* Tangent slope

into one formula.

---

Common examples include:

]

[

]

Understanding these symbols is important because different textbooks use different notation.

## 4.4 Differentiation Rules

Examples include:

* Constant Rule
* Power Rule
* Product Rule
* Quotient Rule
* Chain Rule

These rules make differentiation much faster and are heavily used in machine learning.

*** 59. The Delta Method ***
# Calculus I – The Delta Method (Computing Derivatives from First Principles)

## 1. Overview

The **Delta Method** is a classical technique used to find the **slope of a curve at a specific point**.

The main idea is simple:

* Pick a point on the curve.
* Pick another nearby point.
* Calculate the slope of the line between them (called a secant line).
* Move the second point closer and closer.
* As the distance approaches zero, the secant line becomes the **tangent line**.
* The tangent line's slope is the **derivative**.

This idea is the foundation of differential calculus.

---

# 2. Learning Goal

By the end of this lecture you should understand:

* How to estimate the slope of a curve.
* What Δ (Delta) means.
* Why limits are required for differentiation.
* How the derivative comes from the slope formula.

# 7. Step 5 — Calculate the Slope

The slope between two points is

[
m=\frac{\Delta y}{\Delta x}
]

where

[
\Delta y=y_2-y_1
]

and

[
\Delta x=x_2-x_1
]

Equivalent formula:

[
m=\frac{y_2-y_1}{x_2-x_1}
]

### Python Code

-------------------code----------------------
m = (y2 - y1) / (x2 - x1)
print(m)
-------------------code----------------------

Output

-------------------code----------------------
9
-------------------code----------------------

This is the slope of the **secant line**, not yet the true tangent.

---

Solve for the y-intercept:

[
b=y-mx
]

### Python Code

-------------------code----------------------

print(b)
-------------------code----------------------

Output

-------------------code----------------------

-------------------code----------------------

Now create the entire line.

### Python Code

-------------------code----------------------
line = m*x + b
-------------------code----------------------

# 13. Understanding Delta (Δ)

The Greek letter Delta (Δ) means **change**.

Examples:

Change in x

[
\Delta x=x_2-x_1
]

Change in y

[
\Delta y=y_2-y_1
]

Slope

[
m=\frac{\Delta y}{\Delta x}
]

---

# 14. Why Limits Are Needed

If Q is far away,

the slope only approximates the curve.

As

[
\Delta x\rightarrow0
]

Point Q moves infinitely close to P.

The secant line becomes the tangent line.

That tangent slope is the derivative.

This idea leads directly to the formal derivative definition introduced in the next lecture.

---

# 15. Relationship Between Concepts

-------------------code----------------------
Two points
      ↓
Compute Δy and Δx
      ↓
Compute secant slope
      ↓
Move points closer together
      ↓
Δx → 0
      ↓
Secant becomes tangent
      ↓
Derivative
-------------------code----------------------

---

# 16. Full Final Code

-------------------code----------------------
import numpy as np
import matplotlib.pyplot as plt

# Function
def f(x):
    return x**2 + 2*x + 2

# Generate curve
x = np.linspace(-10, 10, 1000)
y = f(x)

# Point P
x1 = 2
y1 = f(x1)

# Small Delta x
delta_x = 1e-6

# Point Q
x2 = x1 + delta_x
y2 = f(x2)

# Slope
m = (y2 - y1) / (x2 - x1)

# Intercept
b = y1 - m*x1

# Tangent line
line = m*x + b

# Plot
plt.plot(x, y, label="Curve")
plt.scatter(x1, y1, label="P")
plt.scatter(x2, y2, label="Q")
plt.plot(x, line, label="Tangent")

plt.legend()
plt.show()

print("Slope =", m)
-------------------code----------------------

---

# 17. Important Notes

* Δ (Delta) means **change**.
* The slope between two points is called the **secant slope**.
* The slope at one exact point is called the **tangent slope**.
* The derivative is the tangent slope.
* The smaller Δx becomes, the more accurate the slope estimate becomes.
* Limits allow Δx to become infinitely small without actually being zero.

---

# 18. Best Practices

* Always understand the geometry before memorizing formulas.
* Remember that derivatives are simply **instantaneous slopes**.
* Practice computing slopes manually before using differentiation rules.
* Visualize how moving point Q closer to P improves the approximation.
* Keep in mind that every differentiation rule learned later is derived from this simple Delta Method.

---

# 19. Summary

The Delta Method provides an intuitive way to understand derivatives.

The process is:

1. Select a point on the curve.

2. Select a nearby second point.

3. Compute the slope using:

   [
   m=\frac{\Delta y}{\Delta x}
   ]

4. Move the second point closer.

5. Let

   [
   \Delta x\rightarrow0
   ]

6. The secant line becomes the tangent line.

7. The tangent slope is the **derivative**.

This concept is the mathematical foundation for all differentiation techniques and is essential for optimization methods used throughout machine learning, including gradient descent and neural network training.

### Scenario: Training a Model to Predict Prices

#### 1. We have data:
-------------------code----------------------
House Size (x) → Price (y)

120 sqm → 600,000
150 sqm → 750,000
-------------------code----------------------

#### 2. We want to find the best line:
-------------------code----------------------

-------------------code----------------------

#### 3. We define the error (Cost Function):
-------------------code----------------------

-------------------code----------------------

#### 4. We want to minimize the error:
-------------------code----------------------

-------------------code----------------------

-------------------code----------------------
Derivative = Slope of the error curve

#### 6. We use Gradient Descent:
-------------------code----------------------
m_new = m_old - (learning_rate × derivative)
b_new = b_old - (learning_rate × derivative)
-------------------code----------------------

#### 7. We repeat until we reach the best value:
-------------------code----------------------
After 100 iterations:
m = 5,000 (each sqm increases price by 5,000)
b = 0
Error is very small

## Part 7: The Relationship Between Delta Method and Derivatives

### Delta Method = How we calculate the derivative practically

-------------------code----------------------
Delta Method:
1. Take two very close points
2. Calculate the slope between them
3. This slope = the derivative (approximately)

The closer the points, the more accurate the result.
When the distance = 0 (limit), we get the exact derivative.
-------------------code----------------------

### Example with Numbers:

-------------------code----------------------
f(x) = x² at x = 2
True derivative = 4

Using Delta Method:
Δx = 0.1  → slope = 4.1  (approximation)
Δx = 0.01 → slope = 4.01 (more accurate)
Δx = 0    → slope = 4    (exact, using limits)
-------------------code----------------------

## Part 8: Complete Example (Very Simple)

### We want to train a model: y = m × x

#### Data:
-------------------code----------------------
x = [1, 2, 3]
y = [2, 4, 6]
-------------------code----------------------

#### Steps:

**1. Start:**
-------------------code----------------------
m = 0
Error = (0×1-2)² + (0×2-4)² + (0×3-6)² = 4+16+36 = 56
-------------------code----------------------

**2. Calculate derivative (using limits or rules):**
-------------------code----------------------
Derivative = -2 × (y - m×x) × x
At m = 0: derivative = -2 × (2×1 + 4×2 + 6×3) = -2 × 28 = -56
-------------------code----------------------

**3. Update m (Gradient Descent):**
-------------------code----------------------
m_new = 0 - 0.01 × (-56) = 0.56
-------------------code----------------------

**4. Repeat:**
-------------------code----------------------
Iteration 2: m = 0.56 → derivative = -16.8 → m = 0.728
Iteration 3: m = 0.728 → derivative = -9.7 → m = 0.825
...
Iteration 100: m ≈ 2.0 (close to the truth)
-------------------code----------------------
